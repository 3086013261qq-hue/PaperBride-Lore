# worldbook

《纸嫁衣》正式世界书增补层。

本目录不替代 `characters/`、`locations/`、`folklore/` 与 `timeline/fullstack/`。这里只放**需要在最终卡中单独召回，但不属于稳定世界规则正文**的补充条目，例如系列反复梗、演出彩蛋与跨作风格记忆。

## 当前文件
- `系列梗与彩蛋_v1.md`：系列反复演出/玩家熟知梗的世界书条目。

## 硬边界
1. 系列梗条目不是 MVU 装饰说明。
2. 系列梗条目不是新的法术体系，不能因为梗存在就扩写成万能规则。
3. 只在剧情自然涉及对应物件、角色或语境时召回；不要求每回合强行玩梗。
4. 正史事实仍以逐作时间线为准；条目中会显式标注“实机事实 / 系列反复梗 / 元叙事昵称”的层级。
