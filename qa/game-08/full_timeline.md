## 关键事实审计

### 1. 聂莫黎是否被洗白
PASS。

正式线同时记录：
- 她确实被奘铃村双胞胎弃置旧俗伤害；
- 她确实在婴灵事件中出现心软与真实感情；
- 但她也主动把妹妹、宁子服、汤婆婆等纳入自己的渡劫计划，并长期试图用他人生命完成目标。

因此不存在“悲惨身世自动免除责任”的写法。

### 2. 瞎师婆是否是唯一幕后黑手
PASS。

瞎师婆主动绑架、下咒、操纵明梅和婴灵，并以看乐子为欲望；但第五章明确揭示聂莫黎早已把瞎师婆的入局也纳入自己的成仙险局。两者均是主动施害者，互相算计。

### 3. 半刹鬼仙是否写成真仙
PASS。

聂莫黎自己承认并不知道短暂状态是否算“仙”，且该力量迅速衰竭、天地难容。正式线只记录“近似鬼仙/半刹鬼仙状态”与言出法随表现，不升级为稳定神格。

### 4. 聂莫琪的双胞胎怀孕
PASS。

这是第五章末聂莫黎在夺魂时直接发现的剧情事实，并非网络推测。正式线保留为【明示】。

### 5. 聂莫黎与瞎师婆去向
PASS。

结局仅确认搜救队没有找到二人痕迹。没有擅自写“死亡”“被鬼门带走”“逃跑成功”等确定结论。

### 6. 宁子服坠崖结局
PASS。

第四章末按当时角色认知写“生死未明”；第五章尾声再揭示车辆挂在树冠，安全带与气囊救命。没有提前倒灌。

### 7. 冥陀兰现实解释
PASS。

结局社会层把山中大量冥陀兰当作异常事件的重要解释，并计划清理；聂莫琪本人仍明确不能确定经历真假。正式线不把全部灵异强行现实化。

### 8. 魕娘子
PASS。

魕娘子与聂莫黎保持分离：魕娘子是受六葬体系伤害的独立存在；聂莫黎曾通过契约夺取其力量却违约；本作中魕娘子主动与聂莫琪立契并最终间接帮助宁子服找到妻子。

### 9. 网络二创污染
PASS。

没有采用“姐妹彻底和解”“聂莫黎为纯粹救世主”“千子娘等同六葬菩萨本体”“双胞胎孩子必定拥有超能力”等无直接证据扩写。

## 人物因果检查

- 聂莫琪：妇产科检查 → 被绑架/离魂 → 恢复三年前阳魂记忆 → 与魕娘子立契 → 与姐姐临时合作 → 还魂 → 坠崖危机 → 被卷入姐妹渡劫终局 → 怀双胞胎使夺魂失败 → 获宁子服救援。
- 宁子服：收到求救 → 返奘铃村 → 破咒找妻 → 与姐妹汇合 → 修车撤离 → 坠崖生死未明 → 幸存并循盖头救回聂莫琪。
- 聂莫黎：被瞎师婆反咒困住 → 与妹妹合作 → 利用整场险局渡劫 → 短暂进入半刹鬼仙状态 → 再暴露夺取妹妹魂魄的终局计划 → 因妹妹怀双胞胎而失败 → 去向不明。
- 瞎师婆：绑架与下咒 → 利用明梅/樟柳神/婴灵 → 主动烧树逼局势失控 → 揭露聂莫黎布局并继续取乐 → 最终去向不明。
- 明梅：追随聂莫黎 → 被卷入双重操控与催眠/樟柳神影响 → 精神崩溃并攻击 → 现实层存在不在场证明 → 彩蛋继续向“菩萨”祈求。
