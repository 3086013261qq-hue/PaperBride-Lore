## 三、污染审计

### 1. “三个结局/隐藏真结局”网络假攻略
**PASS。**

未采用网络上“BE旧梦空留 / HE罗浮归安 / 隐藏真结局”等说法。实机主线按单一结局封版。

### 2. 聂莫黎复活
**PASS。**

未把所谓“九代隐藏结局复活聂莫黎”写入任何节点。九代主线为赵暮寻、昙露凝与昙父昙母。

### 3. 昙露凝已死/残魂女主
**PASS。**

第三章只把“昙母声称露凝已死”记录为当时信息；后续实机明确露凝仍在行动，并在结尾梦醒后收拾行李离家。因此未采用二创中的“肉身早死、全程残魂”版本。

### 4. 全部是赵暮寻精神幻想
**PASS。**

未采用“叔叔早死、所有灵异都是男主幻想”的玩家脑补。游戏将叔叔后续住院、父母术法、阴司带走等作为实际叙事呈现。

### 5. 禳僖游仙正法目标过度解释
**PASS。**

正式线只确认昙父昙母利用二人进行婚祭、试图施展禳僖游仙正法；不把网络“百分百为了永生/真正成仙”等解释写成已证实机制。

### 6. 罗浮梦=普通梦
**PASS。**

未把“梦醒忘记”倒推为此前一切都没有发生。罗浮入梦有明确术法设计、多人共同作用与现实后果。

### 7. 父母洗白
**PASS。**

昙父昙母即使使用“为你好”话术，正式线仍记录其欺骗、操控、婚祭与强迫行为，不将其重写为单纯救女儿。

## 四、人物因果闭环

### 赵暮寻
梦中结缘 → 不接受告别 → 寻解梦先生 → 被引向益昌 → 经纸人列车抵达 → 识破昙家假死与冥婚 → 被昙露凝救下 → 合作断缘 → 梦醒忘却。

### 昙露凝
被父母长期控制 → 与赵暮寻在梦中相识 → 偷看经书发现阴谋 → 为保护赵暮寻主动断梦并出逃 → 车站破鬼打墙 → 救下赵暮寻 → 与其共同反抗父母 → 断缘梦醒 → 离开昙家。

### 昙父
已死亡仍滞留阳世 → 化身解梦先生接近赵暮寻 → 以劝退为表、引路为实 → 协助婚祭 → 终局强行阻止断缘 → 失败后被阴司带走。

### 昙母
已死亡仍滞留阳世 → 在昙宅伪造女儿死讯 → 把赵暮寻引入冥婚流程 → 继续控制女儿 → 终局阻止断缘 → 失败后被阴司带走。

### 叔叔
父母死后收养赵暮寻 → 参与/被利用于昙家交易链 → 其行为造成赵暮寻被进一步引入局 → 后遭反噬住院；未升级为主谋。
