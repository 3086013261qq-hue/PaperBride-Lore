## 污染审计

### 1. 申旺宗是否被写成“幕后黑手”
PASS。

正式线只确认：申旺宗为延续申家香火向魕娘子祈愿，迷信选择构成鸳鸯债的重要历史诱因；聂莫黎又利用其对王娇彤八字的偏见推动布局。未将所有事件归因于申旺宗主动害人。

### 2. 魕娘子与聂莫黎是否混同
PASS。

正式线区分：
- 历史魕娘子：奘铃村纸新娘中怨气极重、后化厉鬼并被封的存在；
- 聂莫黎：后来夺取魕娘子法力，并以其形象/力量继续布局的人。

没有写成“聂莫黎从一开始就是魕娘子本人”。

### 3. 纸媒婆阵营
PASS。

纸媒婆及纸人鬼通过“娘子替矣”等方式向男女主提示真相，并非聂莫黎同伙。正式线保留其被聂莫黎吞噬、仍试图帮助男女主的功能。

### 4. 王娇彤结局状态
PASS。

未写“第三部结尾王娇彤已经还阳”。正式线写为：剪断红线后魂魄一度进入鬼门关，肉身仍未正常苏醒；但闪灯暗号证明她的魂魄仍存在并能与申墨卿联系。

### 5. 祭魄数量
PASS。

第五章流程明确展示连续祭魄；本作人物总纲明确聂莫黎最终企图让申墨卿牺牲六魄。正式线没有把画面已展示的前三次祭魄错误等同为“全部代价已经付清”。

### 6. 后作倒灌
PASS。

未把《纸嫁衣4～7》中郑宅阴阳裂隙、益昌镇后续、两间口镇最终还阳等内容写入第三部当时认知；仅在“不得提前写死”清单中用于约束后续施工。

### 7. 玩家解析污染
PASS。

未采用“全部都是幻觉”“聂莫黎心理学布局可解释全部鬼怪”“三世轮回已经完全坐实”等玩家二创解析作为正式事实。

## 人物因果检查

- 申墨卿：维护恋人 → 河中救人 → 鬼打墙求医 → 发现王娇彤阳魂 → 阴阳协作追查 → 得知家族鸳鸯债 → 为救王娇彤主动祭魄 → 识破聂莫黎附身，闭环成立。
- 王娇彤：与二爷爷冲突 → 落水后阳魂离体 → 独自在家破符 → 与申墨卿建立联系 → 提出闪灯暗号 → 被聂莫黎绑红线 → 剪断红线阻止男友牺牲，闭环成立。
- 申旺宗：迷信求嗣 → 祈愿牌暴露旧约 → 承认香火愿与代价 → 后期劝申墨卿停止祭魄，人物转变成立。
- 聂莫黎：前作失败后的魂魄状态 → 夺魕娘子法力 → 预先布置玉簪/招邪条件 → 利用二爷爷与王娇彤 → 绑定红线 → 欲借六魄还阳 → 被王娇彤破局，闭环成立。
- 汤婆婆：识别阳魂离体 → 提供招魂知识 → 承认聂莫黎已走偏 → 协助申墨卿，但无法替其承担祭魄代价，功能一致。
- 纸媒婆/纸人鬼：从恐怖障碍逐步反转为“提示真正娘子被替换”的帮助者，叙事功能闭环。
