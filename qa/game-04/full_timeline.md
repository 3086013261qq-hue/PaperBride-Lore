## 污染检查

### 1. 现代崔婉莺 = 民国崔婉莺转世
PASS。

正式线明确二者是不同叙事人物，仅同名且存在记忆/映照要素。本作替死鬼仪式的选择逻辑依赖祭品条件，不以“确定转世”作为必要因果。

### 2. 崔茜姝纯受害者化
PASS。

正式线同时保留两层事实：她生前先害死堂姐并冒名代嫁；随后又被郑家作为祭品献祭并因仪式失败化厉鬼。未将其中任一层覆盖另一层。

### 3. 郑家公开传闻 = 历史事实
PASS。

“新娘急病身亡 / 中邪 / 诅咒请柬”等按公开传闻记录；后段通过郑家文书与仪式线索再揭示真实献祭结构，没有在第二章提前把传闻升级为真相。

### 4. 郑宅大火因果
PASS。

正式线在后见真相层记录崔茜姝献祭失败后，于次年中元节借孔明灯引发郑宅大火并造成灭门；前章角色只接触“郑家失火”的传说，不提前知道施害者。

### 5. 水神煞来源
PASS。

只记录本作能支撑的“郑家以六葬残卷/抄本糅合本地水脉与信仰形成祭祀体系”。没有把后续作品对六葬总源头的补充倒灌为第四部角色当时已知信息。

### 6. 崔婉莺被选中的原因
PASS。

记录为她在布局中逐步满足水神煞祭品条件，因此成为替死鬼目标。未写成“只因血缘”“只因同名”或“只因转世”。

### 7. 聂莫黎 / 申墨卿 / 王娇彤
PASS。

三人只进入结尾彩蛋层。聂莫黎未参与现代主线救援或布局；申墨卿与王娇彤仍延续第三部未完成的回魂问题，未误写王娇彤已经还阳。

## 人物因果检查

- 张辰瑞：早年鬼请柬 → 为保护崔婉莺不告而别并研究民俗 → 益昌镇重逢 → 郑宅调查与救援 → 破局并复合，闭环成立。
- 现代崔婉莺：电子请柬/工作来到益昌镇 → 庙会被牵入迎亲 → 郑宅被选作替死鬼 → 识破水神煞布局 → 与张辰瑞破水脉逃生，闭环成立。
- 民国崔婉莺：原定郑家婚嫁对象 → 被崔茜姝害死，构成崔茜姝冒名代嫁的前置因果。
- 崔茜姝：害死堂姐并代嫁 → 被郑家献祭 → 仪式失败化厉鬼 → 郑宅灭门 → 利用传闻寻找替死鬼 → 现代计划失败，被拘往阴司，闭环成立。
- 郑家：水脉灾祸 → 借六葬体系设计纸新娘婚祭 → 献祭失败 → 纸人寄魂与火灾灭门后留下异常宅院，因果闭环。
