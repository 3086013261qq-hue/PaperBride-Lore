## 污染检查

### 1. “第十三医院才是真现实”
PASS。

第四折中出现完整的精神科解释：钟梓萓自称主治医生、荀元丰被解释为保安、陶梦嫣被解释为从未逃出奘铃村。该段发生在屠浮生施加的灵府幻境中，正式线只记录为“幻术内部自洽叙事”，未覆盖主线现实。

### 2. 冥陀兰是否否定全部灵异
PASS。

屠浮生明确承认在戏院空调中使用冥陀兰致幻花粉；同时他也明确使用家传鬼戏、地支鬼儡法、灵府魇魅术等术法。正式线并列记录，未擅自得出“全部只是药物”或“药物毫无作用”。

### 3. 荀元丰 = 梁少平？
PASS。

本作接受“荀元丰是梁少平转世”的世界观事实，但第五折陶梦嫣明确强调“你不是他，你是荀元丰”。正式线因此将前世联系与今生人格独立同时保留，未把两人写成同一人格。

### 4. 陶梦嫣 = 祝小红？
PASS。

陶梦嫣接受自己与祝小红的前世关系，但本作核心选择是以今生身份作决定。未把陶梦嫣所有感情、行为自动解释为祝小红记忆复刻。

### 5. 屠浮生是否“其实无辜”
PASS。

屠浮生确有自身受害经历与家族压力，但他主动诱骗三人入戏院、使用致幻花粉、鬼儡与灵府术，并试图强制婚祭陶梦嫣。正式线没有因其最终放弃婚祭并提供救人办法而洗去此前加害事实。

### 6. 荀元丰结尾是否已还阳
PASS。

《来生戏》本篇结束时：荀元丰肉身仍在现实、魂魄已进入阴阳裂隙；陶梦嫣出发寻找；钟梓萓留守肉身。后作中王娇彤帮助荀元丰还阳的结果没有倒灌进 game-05 本篇结局。

### 7. 三代/四代彩蛋倒灌
PASS。

结尾只记录荀元丰魂魄在裂隙中遇到申墨卿、王娇彤、聂莫黎。未把后续战斗结果或六代信息写成五代当时已经发生。

## 人物因果检查

- 陶梦嫣：看戏 → 旧事被利用 → 识破假伙伴 → 被灵府幻境击中自我怀疑 → 接受今生身份 → 婚祭破局 → 主动寻魂，闭环成立。
- 荀元丰：被梁少平旧事刺痛 → 因恐惧与自卑被幕后者利用 → 进入陶梦嫣恶梦救人 → 接受“自己是荀元丰” → 持刀救人 → 魂魄离体，闭环成立。
