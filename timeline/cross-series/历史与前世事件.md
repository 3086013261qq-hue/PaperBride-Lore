# 《纸嫁衣》跨作历史 / 前世 / 转世事件表｜v1.0

> 本文件只整理“过去的人是谁、今生是否与其存在转世/继承关系、哪些只是相似或被误认”。  
> 任何“前世=今生人格完全相同”的写法均禁止。

---

# 一、六葬历史层

## 1. 灵哥 / 灵妹
- 时代：至少可追溯至千年前的六葬体系；具体公历年份未明。
- 身份：被六葬体系长期束缚、承担灵童/修塔使命的一对兄妹。
- 后续：因招魂与附身事故进入肖驰体内相关意识结构，千年后在浊土洞天重逢。
- 结论：他们是**独立旧时代个体/意识**，不是肖驰、奚月遥的“前世人格”。
- 来源：game-06 T。

## 2. 历代大巫贤
- 唐代与民国历史映像显示，大巫贤并非一位永恒个体，而是多人继承的职位/权力身份。
- 历代之间存在夺权、投毒、扭曲神谕、扩张旁系等行为。
- 禁止把“大巫贤”当成单一不死角色。
- 来源：game-06 P/Q。

---

# 二、梁少平 / 祝小红线

## 1. 梁少平
- 时代：民国。
- 身份：外来戏子/武生，与祝小红相爱。
- 结局：为阻止纸新娘婚祭被大巫贤一方斩首。
- 死后状态：部分魂魄与煞金刚存在直接关系。
- 来源：game-02 P～AA。

## 2. 祝小红
- 时代：民国。
- 身份：被奘铃村选中的纸新娘。
- 结局：梁少平被杀后跳崖殉情。
- 来源：game-02 S～U。

## 3. 荀元丰 ← 梁少平
- 关系：game-05 明示荀元丰是梁少平转世。
- 但：荀元丰有自己的性格、恐惧、选择与人生。
- 关键台词层结论：陶梦嫣明确强调“你又不是他，你是荀元丰”。
- 正式写法：`梁少平 → 转世关系 → 荀元丰`。
- 禁止写法：`荀元丰=梁少平复活`、`荀元丰只是梁少平人格容器`。
- 来源：game-05 R/U。

## 4. 陶梦嫣 ↔ 祝小红
- 灵异层：旧事重演、噩梦、煞金刚与角色资料均支持“祝小红转世”解释。
- 医学层：肖医生提出童年催眠灌输、冥陀兰致幻、环境暗示等解释。
- 陶梦嫣本人：即使真有前世，也拒绝把今生完全等同祝小红。
- 正式写法：`疑似/被作品强烈指向的转世关系，保留双重解释`。
- 禁止写死：`陶梦嫣客观确定就是祝小红`。
- 来源：game-02 V/AB/AF，game-05 U。

# 三、魕娘子 / 聂莫黎线

## 1. 历史魕娘子
- 本体：独立于聂莫黎存在的纸新娘厉鬼/民俗灵体。
- 相关能力：送子、姻缘债、招魂/阴缘等。
- 申旺宗曾向其求“申家香火不断”。
- game-08 中聂莫琪真正与其接触，进一步坐实“魕娘子≠聂莫黎”。
- 来源：game-03 Q/S，game-08 J。

## 2. 聂莫黎
- 不是魕娘子前世，也不是魕娘子本体。
- 她后来以“解放魕娘子”等承诺换取/夺取其力量，并在三代大量借用魕娘子形象、法力和信物布局。
- 正式写法：`聂莫黎 = 后来掌握并利用魕娘子力量的人`。
- 禁止写法：`聂莫黎就是魕娘子`。
- 来源：game-03 S，game-08 J。

# 四、崔家 / 郑宅线

## 1. 民国崔婉莺
- 时代：民国。
- 身份：原本被郑家选中的婚嫁/婚祭对象。
- 结局：被堂妹崔茜姝推入河中，死亡被伪装成意外。
- 来源：game-04 K。

## 2. 崔茜姝
- 时代：民国。
- 生前：因嫉妒害死堂姐并冒名嫁入郑家。
- 后续：反而被郑家纳入原定水祭；因身份与条件不合，献祭失败后化厉鬼并困于太一水脉。
- 身份双层：**施害者 + 后来的献祭受害者**，两层都必须保留。
- 来源：game-04 K/R。

## 3. 现代崔婉莺
- 与民国崔婉莺同名，但本作没有把二者直接写死为同一灵魂/转世。
- 她被崔茜姝选中，核心原因是满足替死鬼/祭品条件，而非必须建立在“转世”前提上。
- 正式写法：`现代同名者；是否存在转世关系待核/不写死`。
- 来源：game-04 K/R。

# 五、聂家阴命双生线

## 1. 聂莫黎 / 聂莫琪
- 两人为同胞双胞胎，不是前世今生关系。
- 六葬旧俗把“阴命双胞胎”视为冲撞风水，导致姐姐被遗弃。
- 后作中“阴命双生、命理相近”又成为魕娘子契约、半刹鬼仙、夺魂拼仙命等术法利用条件。
- 这是一条**同生双命**线，而非转世线。
- 来源：game-01 G，game-08 J/S/U。

## 2. 聂莫琪腹中双胞胎
- game-08 结尾明示聂莫琪怀孕且为双胞胎。
- 这使聂莫黎原本针对“双生两魂”的最终夺魂计算失效。
- 当前尚无证据证明两个孩子对应任何旧角色转世。
- 禁止把未来孩子擅自写成梁少平/祝小红/灵哥灵妹等转世。
- 来源：game-08 U。

# 六、肖驰 / 奚月遥与灵哥灵妹

## 1. 肖驰
- 现代人，奘铃村肖氏后代。
- 体内曾同时卷入灵哥、灵妹相关附身意识。
- 一度因记忆与身份错位误认自己就是奚月遥。
- 这不是前世觉醒，而是附身/意识错认。
- 来源：game-06 L/T。

## 2. 奚月遥
- 现代人，独立个体。
- 与灵妹之间存在招魂/附身目标关系，但灵妹最终并非稳定“转世成奚月遥”。
- 禁止写成：`奚月遥=灵妹转世`。
- 来源：game-06 T。

---

# 七、李逢泽 / 杜言她

- 两人不是前世今生关系。
- 其核心是相互利用的“金童玉女”命格与阴阳界规则。
- 七代结尾二人成为新的鬼货郎/八不郎，九代彩蛋确认仍在活动。
- 这是身份转化/职位继承，不是转世。
- 来源：game-07 S/T，game-09 U5。

---

# 八、赵暮寻 / 昙露凝

- 二人没有已确认前世关系。
- 他们的“命定感”来自罗浮入梦与禳僖游仙正法的长期人为培养。
- 两人真实产生感情，但最终主动断缘，拒绝让术法把感情变成祭祀工具。
- 禁止因为“牛郎织女”仪式意象就写成二人是牛郎织女转世。
- 来源：game-09 N～U。

# 九、正式转世关系清单

## 已明示/高度坐实
1. **梁少平 → 荀元丰**：明示。

## 强烈指向但保留双重解释
1. **祝小红 ↔ 陶梦嫣**：灵异层强指向，医学层保留其他解释。

## 不得擅自认定
1. 民国崔婉莺 → 现代崔婉莺。
2. 魕娘子 → 聂莫黎。
3. 灵哥 → 肖驰。
4. 灵妹 → 奚月遥。
5. 任何旧角色 → 聂莫琪腹中双胞胎。
6. 牛郎织女 → 赵暮寻/昙露凝。

# 十、跨作使用规则

1. “转世”只在原作明确或证据链极强时进入正式世界书。
2. 前世记忆不自动等于今生人格。
3. 同名、同脸、相似命格、相似遭遇都不能单独证明转世。
4. 附身、夺舍、阳魂离体、身份冒用、术法幻境必须与转世严格区分。
5. 后作确认的真相只进入跨作层，不回写成前作角色当时已经知道。
