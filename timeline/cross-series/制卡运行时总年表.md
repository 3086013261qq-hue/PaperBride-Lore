# 十一、玩家手动换卷规则

1. 所有主线结束后进入稳定 `沙盒模式`。
2. `沙盒模式` 仅表示本卷结束与自由行动，**不得自动切下一卷**。
3. 下一卷必须由玩家在 MVU 主动选择“进入下一卷/开始新篇章”。
4. 日期超过下一卷默认锚点时，不跳过主线；玩家手动进入后执行 `MAIN_DATE_REBASE`。
5. 进入主线后启用 `DATE_LOCK`，保持卷内相对时序。
6. `沙盒模式过渡`、`至 沙盒模式过渡`、`过渡到沙盒模式`、`即将进入沙盒` 均不得改变 ACTIVE 或 MAIN enabled 状态。
