# 《纸嫁衣》宇宙跨作总时间线｜v1.0

> 状态：**跨作总线第一版 / 基于 game-01～09 全部封版时间线整合**  
> 原则：只排列能够被现有九部剧情支撑的先后关系；“作品编号”不自动等于“宇宙时间顺序”。  
> 日期策略：有明确时代写时代；只有相对先后则写“此前/其后/约X年后”；无法稳定排序的事件并列保留，不强排。

## 证据标签
- 【明示】九部已封版时间线直接支持。
- 【跨作后见】需要结合两部或以上作品才能确认。
- 【相对顺序】只能确认前后，不能确认具体年月。
- 【顺序待核】已知都发生在某一时代，但当前证据不足以决定彼此先后。

# A｜六葬体系的古代根基

**A1【跨作后见】**  
六葬菩萨/葬尊信仰在现代剧情发生前已延续极久，并逐步形成大巫贤、纸新娘、阴童子、灵塔、愿力、修塔使命等一整套祭祀结构。  
来源：game-02、game-06、game-08。

**A2【明示】**  
六葬体系长期把儿童、阴命者、纸新娘等人群纳入献祭或“使命”逻辑；后世所谓阴童子、灵童、修塔工具，本质上包含真实受害者。  
来源：game-02 Z，game-06 G/T，game-08 K/Q。

**A3【跨作后见】**  
肖家一脉在六葬体系中长期承担“修灵塔/鬼斧神工”相关责任，并把这种责任作为家族使命代代灌输。  
来源：game-06 I/J。

**A4【明示】**  
灵哥、灵妹原本是一对被六葬体系束缚的兄妹，长期被当作灵童/修塔工具，后因招魂、附身与使命延续而彼此失散。  
来源：game-06 T。

# B｜唐代：教派受外力清剿，但没有消失

**B1【明示】**  
唐代时期，朝廷曾派兵清剿奘铃村的邪异信仰；大巫贤一方选择躲避、保存教派与仪式。  
来源：game-06 P。

**B2【明示】**  
六葬体系内部并非神圣一致：继承者曾以“葬尊托梦”为名毒害前任，并以神意包装权力争夺与牺牲。  
来源：game-06 P。

**B3【跨作后见】**  
唐代清剿并未终结六葬信仰；其仪式、经书、家族使命与旁系信徒继续流传到后世。  
来源：game-06 P/Q，game-04 J，game-02 全作。

# C｜民国旧事一：梁少平与祝小红

**C1【明示】**  
民国时期，奘铃村继续执行“纸新娘”活人婚祭。祝小红被选为纸新娘，梁少平试图带她逃离。  
来源：game-02 P～U。

**C2【明示】**  
梁少平曾进城求助警方，但未能在婚祭前获得有效救援，最终自行返回葬宫救人。  
来源：game-02 Q。

**C3【明示】**  
梁少平被大巫贤以破坏婚祭为由斩首，祝小红随后跳崖殉情。  
来源：game-02 T/U。

**C4【跨作后见】**  
梁少平死后部分魂魄与“煞金刚”形成直接联系，并长期以破坏葬尊神像、干扰纸新娘婚祭等方式反抗六葬体系。  
来源：game-02 AA。

**C5【跨作后见】**  
梁少平后来转世为荀元丰；但后作明确强调“荀元丰是荀元丰”，今生人格不能被前世完全覆盖。  
来源：game-05 R/U。

**C6【双重解释保留】**  
陶梦嫣是否就是祝小红转世，在灵异演出层得到大量支持，但肖医生也给出童年催眠灌输、冥陀兰致幻与环境暗示的医学解释；跨作总线不自行裁定唯一答案。  
来源：game-02 V/AF。

# D｜民国旧事二：益昌郑宅与崔茜姝

> **与 C 段都属民国时期，但当前九部证据不足以稳定判断二者谁先谁后，因此并列。**

**D1【明示】**  
益昌郑家取得与六葬体系有关的残卷/抄本，并把六葬仪式与太一水脉、六王爷信仰及本地婚俗结合。  
来源：game-04 J。

**D2【明示】**  
民国崔婉莺原本是郑家婚祭选中的对象；堂妹崔茜姝因嫉妒将其推入河中，并冒用身份嫁入郑家。  
来源：game-04 K。

**D3【明示】**  
郑家仍按原定方案把“新娘”纳入水脉婚祭，但因实际身份、生辰等条件不符，仪式失败。  
来源：game-04 K/Q/R。

**D4【明示】**  
崔茜姝死后化为厉鬼并被困在太一水脉；次年中元节，她借孔明灯等异常引发郑宅大火，郑家灭门。  
来源：game-04 N/R。

**D5【跨作后见】**  
郑宅此后长期保留六葬残卷、纸人寄魂与水脉祭祀痕迹；这些遗留后来被聂莫黎继续寻找和利用。  
来源：game-04 S5。

# E｜现代前史：聂家阴命双胞胎与聂莫黎成长

**E1【明示】**  
聂家诞下阴命双胞胎聂莫黎、聂莫琪；奘铃村旧俗认为双胞胎会冲撞六葬菩萨，只能留下一个孩子。  
来源：game-01 G。

**E2【明示】**  
姐姐聂莫黎被遗弃，后被汤婆婆捡回并抚养；妹妹聂莫琪留在聂家正常成长。  
来源：game-01 G/Q。

**E3【明示】**  
汤婆婆长期让莫黎远离村子，后又送其外出读书；莫黎约在一代事件前两年得知自己的真实身世。  
来源：game-01 Q。

**E4【明示】**  
莫黎因身世与人生落差产生强烈怨恨，转而接近汤婆婆师兄并学习邪术，最终把“夺回妹妹的人生”当作目标。  
来源：game-01 Q/U。

**E5【认知边界】**  
聂家父母之死只存在汤婆婆对莫黎的怀疑；现有资料不能写成“莫黎确定杀害父母”。  
来源：game-01 Q5。

# F｜现代第一阶段：game-01《纸嫁衣》

**F1【明示】**  
宁子服与聂莫琪准备结婚；婚礼当天发生纸嫁衣、纸人、失踪与日期异常，宁子服开始追查妻子去向。  
来源：game-01 A～D。

**F2【明示】**  
宁子服由奘铃村旧宅、汤婆婆与双胞胎证据得知聂莫黎存在，并一度误以为白衣女子是姐姐鬼魂。  
来源：game-01 E～H/Q。

**F3【跨作后见】**  
真正的白衣女子其实是聂莫琪的阳魂；聂莫黎与假道士利用离魂、夺寿与致幻药物，把聂莫琪肉身囚在殡仪用品店地下密室。  
来源：game-01 R/U/V/Z。

**F4【明示】**  
宁子服完成招魂，聂莫琪醒来；警方随后救出二人，并在地下室找到昏迷、近似失魂的聂莫黎与假道士。  
来源：game-01 X/Y。

**F5【明示】**  
聂莫黎与假道士被送往第十三精神病医院；奚医生、肖医生等人的奘铃村背景由此与主线连接。  
来源：game-01 AB。

**F6【明示】**  
原婚礼推迟数日后重新举行，宁子服与真正的聂莫琪完成婚姻关系。  
来源：game-01 AA。

# G｜现代第二阶段：约一代次年的 game-02《奘铃村》

**G1【相对顺序】**  
约在一代事件后的次年，成年陶梦嫣因自幼反复出现的纸新娘噩梦返回故乡奘铃村。  
来源：game-02 AG1 对“去年入院的聂某等二人”的提及。

**G2【明示】**  
村长/大巫贤与村民将陶梦嫣当作纸新娘，实施非法拘禁并试图完成婚祭。  
来源：game-02 B～E。

**G3【明示】**  
陶梦嫣通过鬼戏与灵塔重经历梁少平、祝小红旧事，逐步揭开煞金刚、阴童子与六葬祭祀真相。  
来源：game-02 L～AA。

**G4【明示】**  
陶梦嫣拒绝把自己完全等同为祝小红，也劝梁少平相关魂魄放下旧缘。  
来源：game-02 AB。

**G5【明示】**  
她焚毁重要六葬经书并逃离；村长等人进入司法程序。  
来源：game-02 AD/AE。

**G6【跨作后见】**  
肖医生发现冥陀兰等致幻证据，同时私下继续研究六葬体系；这一选择成为第十三医院后续事故的重要前置。  
来源：game-02 AF/AG。

# H｜现代第三阶段：game-03《鸳鸯债》→ game-04《红丝缠》→ game-05《来生戏》

**H1【明示】**  
申旺宗早年曾向魕娘子祈愿“申家香火不断”，申墨卿因此背上鸳鸯债相关因果。  
来源：game-03 Q。

**H2【明示】**  
王娇彤遭聂莫黎布局而阳魂离体；历史魕娘子与聂莫黎并非同一存在，聂莫黎只是后来夺取并使用其力量。  
来源：game-03 O/S/V。

**H3【明示】**  
聂莫黎试图让申墨卿牺牲六魄，把与自己红线相连的王娇彤一同带回阳间，以推进自身渡劫/鬼仙计划。  
来源：game-03 T～V。

**H4【明示】**  
王娇彤主动剪断红线，聂莫黎计划失败；本作结束时王娇彤尚未正式还阳，但能用“一长两短”与申墨卿联系。  
来源：game-03 W。

**H5【相对顺序】**  
随后益昌郑宅事件发生。现代崔婉莺、张辰瑞进入郑家遗留的太一水脉婚祭困局，并击破崔茜姝寻找替死鬼的计划。  
来源：game-04 全作。

**H6【明示】**  
崔茜姝最终被黑白无常拘往阴司；郑宅保留的六葬残卷/神像继续吸引聂莫黎调查。  
来源：game-04 S。

**H7【相对顺序】**  
《来生戏》时，屠浮生把陶梦嫣、荀元丰、钟梓萓引入戏院，试图再次实施纸新娘婚祭。  
来源：game-05 Q/R。

**H8【明示】**  
屠浮生确认荀元丰是梁少平转世，同时使用冥陀兰、鬼儡与灵府幻术攻击三人。  
来源：game-05 R。

**H9【明示】**  
三人破坏婚祭后，荀元丰因魂魄不稳及斩煞刀影响而魂魄离体；陶梦嫣前往阴阳裂隙寻魂。  
来源：game-05 W～Z。

**H10【跨作后见】**  
荀元丰魂魄在阴阳裂隙一侧遇到申墨卿、王娇彤与聂莫黎，三代、四代彩蛋线与五代结局开始汇流。  
来源：game-05 AA。

# I｜现代第四阶段：game-06《千秋魇》

**I1【相对顺序】**  
《千秋魇》明确发生在《来生戏》之后；肖驰、奚月遥与第十三医院、奘铃村六葬研究线正式汇合。  
来源：game-06 时间锚点。

**I2【明示】**  
肖驰逐渐恢复身份认知，确认自己此前一度误认自己就是奚月遥；真正的奚月遥随后与其重逢。  
来源：game-06 L/M。

**I3【明示】**  
二人追入后山六葬灵塔，看到唐代、民国历史映像，确认六葬体系长期存在内斗、献祭、修塔与对外扩张。  
来源：game-06 N～Q。

**I4【明示】**  
肖驰、奚月遥进入浊土洞天，最终帮助灵哥灵妹重逢；兄妹主动放弃继续修塔的千年使命。  
来源：game-06 R～U。

**I5【明示】**  
奚月遥返回现世；肖驰因脚伤无法同样跨越出口，留在浊土洞天继续寻找解除奚家问题的方法。  
来源：game-06 U。

**I6【跨作后见】**  
彩蛋显示申墨卿、王娇彤、张辰瑞、崔婉莺已经因阴阳通信/还阳事件产生直接联系，前四作现代人物线进一步汇合。  
来源：game-06 U5。

# J｜现代第五阶段：game-07《卿不负》

**J1【相对顺序】**  
申墨卿继续寻找让王娇彤完整回归的方法，两人进入/卷入两间口与阴阳界体系；李逢泽、杜言她也在同一系统中行动。  
来源：game-07 全作。

**J2【明示】**  
杜言她并非单纯失忆受害者，她主动利用无字谶、八不郎与王娇彤布局“金童玉女祭祀”。  
来源：game-07 N～R。

**J3【明示】**  
“柳逢泽”真实姓名为李逢泽；他同样长期隐藏利用杜言她完成自身命格需求的私心。  
来源：game-07 S。

**J4【明示】**  
李逢泽与杜言她确认彼此都在算计对方后选择暂时合作，试图共享回魂名额离开。  
来源：game-07 T。

**J5【明示】**  
八不郎与谛听反算二人，李逢泽、杜言她成为新的鬼货郎/八不郎；原八不郎脱离旧身份。  
来源：game-07 T。

**J6【明示】**  
申墨卿与王娇彤成功团聚并离开阴阳界；到此，三代留下的“王娇彤未还阳”状态完成阶段性闭环。  
来源：game-07 T5。

# K｜现代后期：game-08《千子树》

**K1【明示】**  
《千子树》主要发生在《纸嫁衣》第一部约三年后。聂莫琪此时已婚，并前往妇产科检查。  
来源：game-08 时间说明/A。

**K2【明示】**  
聂莫琪重新遭遇阳魂离体，并得知聂莫黎在一代入院后失踪，三年间下落不明。  
来源：game-08 C/I。

**K3【明示】**  
聂莫琪真正接触历史魕娘子；魕娘子确认自己与聂莫黎并非同一存在，并说明莫黎曾以“解放她”为条件换取力量却未履约。  
来源：game-08 J。

**K4【明示】**  
千子树/千子娘事件进一步揭露六葬体系对婴童、纸新娘和被遗弃者的长期利用。  
来源：game-08 K/Q。

**K5【明示】**  
瞎师婆与聂莫黎彼此算计；聂莫黎早已把这场危局纳入自己的“以鬼成仙”渡劫局。  
来源：game-08 R。

**K6【明示】**  
聂莫黎、聂莫琪一度进入短暂“半刹鬼仙”状态；妹妹坚持不能用力量替别人决定人生，姐姐则试图以力量重写不公。  
来源：game-08 S/T。

**K7【明示】**  
聂莫黎最终计划是夺取聂莫琪魂魄，以阴命双生拼成完整仙命；但聂莫琪已怀双胞胎，多出的两个新生命使计划失控。  
来源：game-08 U。

**K8【明示】**  
宁子服幸存并救出聂莫琪；聂莫黎与瞎师婆最终去向未确认。结尾显示六葬菩萨像失踪，六葬因果仍未终结。  
来源：game-08 U。

# L｜现代后期独立线：game-09《罗浮梦》

> **九代主线与八代主线之间的精确先后，目前九部现有证据不足以写死，因此不强行排为“八代之后若干月/年”。**

**L1【明示】**  
赵暮寻、昙露凝因“罗浮入梦之法”在长期连续梦境中相识相恋；二人现实中相隔千里，从未真正见面。  
来源：game-09 A/B。

**L2【跨作后见】**  
昙父、昙母早已死亡，却以玄术令魂魄滞留阳世，并把赵暮寻、昙露凝的一年多梦中关系培养为“禳僖游仙正法”的祭祀条件。  
来源：game-09 N/R。

**L3【明示】**  
赵暮寻追到益昌，二人首次真正见面，并确认梦中相识并非普通梦，而是父母控制下的长期术法结构。  
来源：game-09 O。

**L4【明示】**  
二人主动选择断缘，即使知道代价可能是忘记彼此，也拒绝继续被所谓“命定姻缘”操控。  
来源：game-09 S。

**L5【明示】**  
昙父、昙母婚祭失败并被阴司带走；赵暮寻、昙露凝梦醒后失去完整结缘记忆，但仍保留无法解释的情绪余痕。  
来源：game-09 T/U。

**L6【明示·彩蛋】**  
片尾显示李逢泽、杜言她仍在阴阳体系中活动，并取得/使用离开鬼门关相关票据；七代结局并非他们故事的最终终点。  
来源：game-09 U5。

# M｜当前宇宙状态（截至 game-09）

**M1** 六葬体系经历千年延续、清剿、内斗、旁支传播、现代复燃，但仍未被彻底消灭；game-08 甚至留下六葬菩萨像失踪的悬念。  
**M2** 奘铃村已从“活人村落”转为大量遗迹、愿力、灵体与旧仪式残留的核心地点。
