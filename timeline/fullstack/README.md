## 日期规则

1. 原作给出时辰/相对时刻时，在制卡原创公历日期上保留该时刻。
2. 原作无公历年份时，日期属于 `【制卡原创锚定】`，不回写原作事实层。
3. 同一章连续事件可共享同一公历日；跨午夜的作品允许进入次日。
4. 历史旧事、记忆、投影、幻境的运行时日期表示“玩家/角色在该日经历或获知该节点”，不把唐代/民国旧事改写成现代发生。
5. 主线之间保留自由行动窗口，不做日期到点自动跳剧情。
6. 玩家自由活动超过下一卷默认日期时，由后续运行时层执行 `MAIN_DATE_REBASE`，整卷顺延；进入卷内后使用 `DATE_LOCK` 保证内部顺序。

## 切卷硬规则

- 每卷结尾必须进入稳定状态 **`沙盒模式`**。
- `沙盒模式过渡`、`至 沙盒模式过渡`、`过渡到沙盒模式`、`即将进入沙盒` 只表示收束阶段，**不得作为 MAIN handoff 条件**。
- 后续 MVU 只有在确认稳定 `沙盒模式` 后，才允许把下一 MAIN 设为 enabled 并关闭当前 MAIN。
- 本目录只提供剧情块与稳定尾状态；具体 `enabled / ACTIVE / MAIN_HANDOFF / SANDBOX_PENDING` 交给后续装配阶段。

## 节点规则

- 保持原封版时间线的事件编号和认知边界。
- 一节点尽量只写一个事实。
- 不把后作真相倒灌进前卷角色当时认知。
- 不把科学解释与灵异演出强行合并成唯一真相。
- 不因制卡日期化删减、合并原封版剧情节点。
