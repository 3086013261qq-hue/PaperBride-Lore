## 日期规则

1. 原作给出时辰/相对时刻时，在制卡原创公历日期上保留该时刻。
2. 原作无公历年份时，日期属于 `【制卡原创锚定】`，不回写原作事实层。
3. 同一章连续事件可共享同一公历日；跨午夜的作品允许进入次日。
4. 历史旧事、记忆、投影、幻境的运行时日期表示“玩家/角色在该日经历或获知该节点”，不把唐代/民国旧事改写成现代发生。
5. 主线之间保留长时间自由行动窗口；日期到点**绝不自动开启下一卷**。
6. 玩家主动进入下一卷时，若实际自由活动时间已超过默认起点，可由装配层执行 `MAIN_DATE_REBASE` 整卷顺延；进入卷内后使用 `DATE_LOCK` 保证内部顺序。

## 切卷硬规则｜手动进入制

- 每卷结尾进入稳定状态 **`沙盒模式`**，仅表示“本卷正式剧情结束，进入长期自由行动阶段”。
- **`沙盒模式` 不触发自动切卷，不触发自动 MAIN handoff。**
- `沙盒模式过渡`、`至 沙盒模式过渡`、`过渡到沙盒模式`、`即将进入沙盒` 同样不得触发切卷。
- 下一 MAIN 只有在玩家于 MVU 明确执行“进入下一卷 / 开始新篇章”操作后，才允许切换 `enabled / ACTIVE`。
- 玩家未主动进入下一卷时，当前卷保持有效；即使现实日期已越过下一卷默认日期，也不得自动宣告后续剧情发生。
- 因此纸嫁衣不采用《明日方舟》那种“稳定沙盒 → 自动 MAIN_HANDOFF”结构；这里只复用卷级 `enabled / ACTIVE` 管理，不复用自动衔接逻辑。
- `SANDBOX_PENDING` 如后续保留，只能用于 UI 表示“本卷正在收束”，不得参与切卷。

## 节点规则

- 保持原封版时间线的事件编号和认知边界。
- 一节点尽量只写一个事实。
- 不把后作真相倒灌进前卷角色当时认知。
- 不把科学解释与灵异演出强行合并成唯一真相。
- 不因制卡日期化删减、合并原封版剧情节点。
