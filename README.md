## 核心原则

1. 游戏实际演出 / 对白优先。
2. 官方资料高于民间总结。
3. BWIKI 与完整攻略只用于还原流程，不把攻略作者解释升级为原作事实。
4. 原作事实层不虚构日期、动机、前世关系、幕后身份或因果。
5. 制卡运行时层允许原创日期，但必须明确与官方事实分层。
6. 后作补充只进入跨作后见层，不回写污染前作角色当时认知。
7. 转世、附身、阳魂离体、冒名、同名与身份继承严格区分。
8. 科学解释与灵异演出并存，不做单边裁定。
9. 日期到达不得自动宣告未触发主线已经发生。
10. `chara-v1` 不擅自增删字段；能力与人物正文分离。
11. 非人角色保留真实纸人/灵体/异兽体态，不强行人体化。
