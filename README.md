## 核心原则
1. 游戏实际演出 / 对白优先，官方资料高于民间总结。
2. 原作事实层不虚构日期、动机、身份或因果；运行时原创日期必须明确分层。
3. 后作补充只进入跨作后见层，不回写污染前作当时认知。
4. 转世、附身、阳魂离体、冒名、同名、身份继承与称号严格区分。
5. 科学解释与灵异演出并存，不做单边裁定。
6. `chara-v1` 不增删字段；能力与人物正文分离。
7. 非人角色保留真实纸人/灵体/异兽体态，不强行人体化。
