# PaperBride-Lore

《纸嫁衣》系列剧情 / 世界观资料库。

当前阶段：**剧情优先**。先完成《纸嫁衣》1～9逐作剧情资料与时间线，再处理跨作总时间线、人物、地点、民俗/术法/鬼神，最后才进入角色卡、世界书与 MVU 装配。

## 核心原则

1. 游戏实际演出 / 对白优先。
2. 官方资料高于民间总结。
3. BWIKI 与完整攻略可用于还原事件流程，但不得把攻略作者的解释直接当成原作事实。
4. 玩家解析只作为检索线索，不直接进入正式时间线。
5. 不虚构日期、动机、前世关系、幕后身份或因果。
6. 所有关键节点保留证据等级，便于后续 QA。
