## 核心原则

1. 游戏实际演出 / 对白优先。
2. 官方资料高于民间总结。
3. BWIKI 与完整攻略可用于还原事件流程，但不得把攻略作者的解释直接当成原作事实。
4. 玩家解析只作为检索线索，不直接进入正式时间线。
5. 不虚构日期、动机、前世关系、幕后身份或因果。
6. 所有关键节点保留证据等级，便于后续 QA。
7. 完成单作后先封版；后作补充只进入 `timeline/cross-series/`，不回写污染前作角色当时认知。
8. 作品编号不自动等于宇宙真实时间顺序。
9. 转世、附身、阳魂离体、冒名、同名与身份继承必须严格区分。
10. 冥陀兰/医学解释与真实术法/灵异演出长期并存，不做“全是幻觉”或“全是鬼神”的单边裁定。
