## 核心原则

1. 游戏实际演出 / 对白优先。
2. 官方资料高于民间总结。
3. BWIKI 与完整攻略可用于还原事件流程，但不得把攻略作者的解释直接当成原作事实。
4. 玩家解析只作为检索线索，不直接进入正式时间线。
5. 原作事实层不虚构日期、动机、前世关系、幕后身份或因果。
6. 制卡运行时层允许为缺失年月补 `【制卡原创锚定】`，但必须与原作事实层分离。
7. 所有关键节点保留证据等级，便于后续 QA。
8. 完成单作后先封版；后作补充只进入 `timeline/cross-series/`，不回写污染前作角色当时认知。
9. 作品编号不自动等于宇宙真实时间顺序。
10. 转世、附身、阳魂离体、冒名、同名与身份继承必须严格区分。
11. 冥陀兰/医学解释与真实术法/灵异演出长期并存，不做“全是幻觉”或“全是鬼神”的单边裁定。
12. 日期不是剧情事实源；日期到达不得自动宣告未触发主线已经发生。
13. 角色卡不得把同名、伪装身份、转世、附身或称号关系错误合并。
