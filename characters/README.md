## 角色工程原则
1. 同名不等于同一人：现代崔婉莺与民国崔婉莺分开。
2. 称号不等于单一角色：“大巫贤”作为称号/制度处理。
3. 转世不覆盖今生人格；附身不等于转世。
4. 能力不塞 `chara-v1` 人物正文；稳定能力另建 `<核心设定:角色名·能力>`。
5. 外貌优先用官方/BWIKI立绘校准；资料不足时保守写，不从二创补造。
6. 非人角色保留纸人/灵体/异兽真实体态，不强行人体化。
7. 当前状态只取最后一次明确出场；后作不倒灌前作认知。
