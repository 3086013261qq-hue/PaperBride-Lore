## 角色工程原则

1. **先总表、后人物正文。** 先完成去重、身份边界、登场作品、当前状态与制卡优先级，再逐一写人物资料。
2. **同名不等于同一人。** 现代崔婉莺与民国崔婉莺必须分开。
3. **称号不等于单一角色。** “大巫贤”跨时代由不同人物担任，作为称号/制度条目处理，不强行合并成一个人物。
4. **转世不覆盖今生人格。** 梁少平→荀元丰可以记录转世关系，但角色卡必须分别建立；祝小红↔陶梦嫣继续保留双重解释边界。
5. **附身不等于转世。** 灵哥、灵妹、肖驰、奚月遥分别建立，禁止把附身关系写成前世今生。
6. **灵体/纸人/鬼物按独立人格程度决定。** 魕娘子、千子娘、纸媒婆、八不郎、谛听等有稳定行为与剧情作用者进入角色表；六葬菩萨、阴童子群体等更适合世界书者另列。
7. **当前状态只取最后一次明确出场。** 彩蛋只更新状态，不倒灌前作当时认知。
8. 后续人物正文优先使用已封版剧情事实，再用官方/高质量角色页补外貌、生日、别名、职业等不影响剧情因果的字段。
