## 角色工程原则

1. 同名不等于同一人：现代崔婉莺与民国崔婉莺分开。
2. 称号不等于单一角色：“大巫贤”作为称号/制度处理。
3. 转世不覆盖今生人格：梁少平与荀元丰分别建卡；祝小红/陶梦嫣保留双解释。
4. 附身不等于转世：灵哥、灵妹、肖驰、奚月遥分别建立。
5. 能力不塞 `chara-v1` 人物正文；稳定能力另建 `<核心设定:角色名·能力>`。
6. 外貌优先用官方/BWIKI立绘校准，不从二创补造精确身高、体重、三围或罩杯。
7. 当前状态只取最后一次明确出场；彩蛋只更新状态，不倒灌前作认知。
8. 非人角色允许在原生字段内写“纸人/灵体/异兽体态”，不强行人体化。
