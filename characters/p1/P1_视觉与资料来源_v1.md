# P1｜视觉与资料来源 v1

> 用途：记录 P1 角色卡的外貌与身份校准来源。剧情、关系、结局以仓库封版时间线为第一事实源；公开角色页和官方壁纸用于补稳定外观。

## 统一来源
- 纸嫁衣 BWIKI：https://wiki.biligame.com/zhijiayi/
- 纸嫁衣 BWIKI 游戏壁纸：https://wiki.biligame.com/zhijiayi/游戏壁纸
- 《纸嫁衣9：罗浮梦》公开角色资料页：用于昙父、昙母身份和解梦先生伪装关系交叉核对。

## 逐角色校准

### 道士
- BWIKI角色页：https://wiki.biligame.com/zhijiayi/角色/道士
- 明确：game-01 / game-03 / game-07 为同一角色；蓝色道袍、豆豆眉、白色山羊胡、眼窝下凹；三代彩蛋可见花白发髻。
- 明确：汤婆婆师兄、聂莫黎早期师父；掌握下咒、夺寿与请神等邪术。

### 申旺宗
- BWIKI角色页：https://wiki.biligame.com/zhijiayi/角色/申旺宗
- 明确：末水村老人，极看重申家香火；早年向魕娘子求“申家香火不断”，成为鸳鸯债重要前因。
- 外貌以 game-03 实机老人形象校准，不补造精确身高体重。

### 纸媒婆
- BWIKI角色页：https://wiki.biligame.com/zhijiayi/角色/纸媒婆
- 公开角色资料明确：魕娘子身边纸人鬼；左侧嘴角媒婆痣、手持烟斗。
- 官方/BWIKI壁纸存在纸媒婆主题，可作为纸扎媒婆服装总方向。

### 千子娘
- game-03 / game-08 封版剧情为第一事实源。
- game-03 明确为奘铃村曾祭拜、后受封印的存在；申墨卿酒祭后获得帮助。
- game-08 进一步把千子树、婴灵与被遗弃/祭祀儿童因果连到千子娘体系。
- 具体人体外观缺少稳定统一官方参数，因此人物卡只写“古旧女性灵体/祭祀存在”级别，不虚构五官与三围。

### 崔茜姝
- BWIKI角色页：https://wiki.biligame.com/zhijiayi/角色/崔茜姝
- 《纸嫁衣4》初始设定草图与官方壁纸可见红嫁衣、新娘头面。
- 明确：害死堂姐并冒名代嫁，随后反被郑家献祭；死后化厉鬼困于太一水脉。

### 郑厚仁
- 《纸嫁衣4》封版剧情＋公开角色资料交叉核对。
- 明确：郑老爷、郑家末代家主；主导纸祭化煞与纸人寄魂；死后以纸人鬼形态残存。
- 生前外貌只写民国富户家主式长衫/传统外衣，不虚构精确服装纹样。

### 郑枚曲
- BWIKI角色页：https://wiki.biligame.com/zhijiayi/角色/郑枚曲
- 明确：民国郑家大少爷、郑厚仁之子，婚娶/水脉祭祀旧事核心人物之一。
- 视觉采用民国富家青年＋传统新郎礼服方向，不虚构未公开身体参数。

### 八不郎
- BWIKI角色页：https://wiki.biligame.com/zhijiayi/角色/八不郎
- BWIKI游戏壁纸有“八不郎”及“新任八不郎·杜言她与李逢泽”独立主题，证明原八不郎与后继身份需要分开。
- 人物卡仅固定“两间口鬼货郎/纸人化交易者”视觉方向，不把某个谜题中的帽子、假发永久写死为唯一外观。

### 谛听
- 《纸嫁衣7》实机与公开资料明确：地藏体系异兽，双眼多瞳、类舞狮/孝狮，体型巨大；官方宣传强调“毛茸茸”。
- 能力明确为辨妄，反复妄语者会被吞食。
- 不使用人类发色、胸部、鞋履等常规模板描述替代其异兽结构。

### 昙父
- 公开角色资料明确：昙露凝父亲；别名/伪装身份“解梦先生”；死后以玄术滞留阳世。
- game-09 封版剧情明确其与昙母共同布置罗浮入梦和禳僖游仙正法。
- 外观采用中年、儒雅、传统解梦先生方向，不从二创图补品牌/身材数值。

### 昙母
- 公开角色资料明确：昙露凝母亲；与昙父共同维持罗浮梦、伪造女儿死讯并推进婚祭。
- 外观采用中年、端庄、传统女性衣装方向；不根据同人图补精确颜色、身高或三围。

## 统一约束
1. 非人角色的 `身材/胸部/鞋子` 按纸人、灵体、异兽真实形态写，不强行人体化。
2. 只有官方/BWIKI明确的稳定识别特征才写死；谜题临时装扮不升级为角色常服。
3. P1 同样不虚构身高、体重、罩杯、三围。
4. 角色结局/身份优先服从 `timeline/games/` 与 `timeline/cross-series/`，公开百科仅作查漏和视觉辅助。
