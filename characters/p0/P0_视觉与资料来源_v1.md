# P0｜视觉与资料来源 v1

> 用途：记录 P0 角色卡的外貌校准来源。人物剧情、关系与心理以仓库封版时间线为第一事实源；外貌、生日、别名、官方设计稿等辅助信息优先取《纸嫁衣》BWIKI角色页、官方微博/官方壁纸及游戏内立绘。
>
> 当前 P0 角色卡遵循咩咩全栈 `chara-v1`：`身材`写“身高cm,体重kg,体态描述”，成年女性`胸部`写具体罩杯与视觉描述，成年男性写胸廓/肌肉度。若官方未公布身高、体重、罩杯，允许仅依据官方立绘、游戏内立绘、官方壁纸与同画面人物比例做视觉推定，并在本文件/审计中明确标为“视觉推定”，不得伪装成官方设定。

## 视觉字段约束
1. `发色/发型/瞳色/上衣/下装/配饰/鞋子`：只写稳定可见或多版本共同特征。
2. `身材`：P0 使用 `身高cm,体重kg,体态描述`；无官方数字时使用官方视觉推定，并在审计表留痕。
3. `胸部`：成年女性 P0 写具体罩杯＋视觉描述；无官方数据时只按官方立绘比例推定。成年男性写胸廓/肌肉度。未成年角色禁止罩杯或成人性征推定。
4. 同一角色多作换装时：人物卡使用最具代表性或最新稳定现代造型；篇章限定婚服/灵体形态留给对应剧情或能力/世界书条目。
5. 宁子服以 game-08 官方优化后方向优先，不采用上线初版已被官方调整的脸部设计作为最终基准。
6. 所有推定数字只服务于角色卡一致性与画面描述，不得在剧情中被当作“官方公开设定”“体检记录”或世界内证据。
