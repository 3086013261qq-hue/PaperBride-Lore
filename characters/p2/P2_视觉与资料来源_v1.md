# P2｜视觉与资料来源 v1

> P2 角色资料量普遍较少。人物剧情与关系仍以仓库九部封版时间线为第一事实源；外貌优先取 BWIKI 角色页、游戏内立绘和公开角色资料。缺少稳定立绘细节时，人物卡只保留时代、年龄层和职业/身份能支持的保守外观，不从二创补造。

## 统一来源
- 纸嫁衣 BWIKI 角色导航与角色页：https://wiki.biligame.com/zhijiayi/
- game-01～09 已封版时间线与跨作人物关系表
- 《纸嫁衣9：罗浮梦》公开角色资料

## 逐人说明
- 鬼老头：BWIKI 有独立角色页，game-01 正文确认其为与道士敌对/干扰道士行动的老年男性鬼魂；外貌细节公开资料有限，因此仅保留“老年男性灵体、灰暗朴素衣装”级别描述。
- 陶母：BWIKI 明确其故乡为奘铃村，登场于《奘铃村》《来生戏》；外观按中年母亲与现代朴素衣装保守处理，不补身高体重。
- 崔婉莺（民国）：身份来自 game-04 郑宅旧事。与现代崔婉莺严格分开；民国衣装仅写时代与富家小姐层级，不虚构特定旗袍纹样、首饰品牌或精确身体数据。
- 肖父：BWIKI 明确为奘铃村肖工匠后代、六葬菩萨信徒，强迫幼年肖驰背古书并承担修塔使命；人物卡按奘铃村成年男性、朴素旧式衣装处理。
- 奚母：BWIKI 有独立角色页并列入 game-06；结合封版时间线确认其为奚月遥母亲并参与暴雨上山祭拜旧事。公开外观细节有限，因此保守处理。
- 鲍大人：game-07/后续公开资料确认其为网络主播，试图采访申墨卿、王娇彤相关事件；外观只保留现代主播/拍摄设备特征。
- 柳大师：BWIKI 有独立角色页，game-07 背景确认其与李逢泽的厌胜威胁相关；公开正面立绘细节不足，因此不写死具体发型、法袍纹样。
- 赵暮寻叔叔：《罗浮梦》公开角色资料确认其在赵暮寻父母去世后为赔偿/家产收养赵暮寻，教其维修手艺，后出卖赵暮寻并遭反噬住院；公开形象细节有限，按普通市井成年男性保守处理。

## 视觉约束
1. `身材/胸部` 仅写画面级或年龄层描述，不虚构精确数值。
2. 资料不足时宁可写“无稳定可确认显著配饰”，也不从同人或二创图补细节。
3. 民国崔婉莺与现代崔婉莺视觉条目严格分开。
4. 鬼老头的“灵体状态”属于存在形态，不独立拆成能力条目。
