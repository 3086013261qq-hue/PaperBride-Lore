# P2｜独立能力条目 v1

> P2 仅为具有稳定、可核实术法体系的角色拆能力条目。普通职业技能、亲属关系、鬼魂状态不等同于独立技能树。

<核心设定:柳大师·能力>
核心能力:掌握厌胜、真名制约与相关邪术，能够利用目标的姓名、命格或关联物建立长期威胁与控制。
术法:厌胜术、真名制约、诅咒与玄学交易类手段。
法器:符咒、记录真名/命格的媒介及厌胜相关法物；具体形制以实际剧情为准，不扩写未明示器具。
效果:可令受术者长期处于被威胁、被控制或担心遭术法反噬的状态，并迫使对方隐藏真名、寻求其他玄学路径自保。
代表性用法:对李逢泽形成长期厌胜威胁，使其极度重视真名保密与摆脱术法控制。
限制:现有九部对柳大师正面施法演出有限，能力条目只保留已被剧情支持的厌胜/真名威胁，不补造更高阶法术或战斗能力。
</核心设定:柳大师·能力>
