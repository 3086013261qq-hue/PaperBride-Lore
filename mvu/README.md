# PaperBride MVU

《纸嫁衣》咩咩全栈 MVU。

> 核心原则：**业务只保留两块：手动篇章选择 + 网易云音乐。**
>
> 禁止把 MVU 扩写成剧情导演、人物状态面板、收藏册、背包、成就、地图、自动切卷系统或第二套世界事实源。

## 1. 篇章选择

正式卷序：

1. MAIN01《纸嫁衣》
2. MAIN02《纸嫁衣2：奘铃村》
3. MAIN03《纸嫁衣3：鸳鸯债》
4. MAIN04《纸嫁衣4：红丝缠》
5. MAIN05《纸嫁衣5：来生戏》
6. MAIN06《纸嫁衣6：千秋魇》
7. MAIN07《纸嫁衣7：卿不负》
8. MAIN08《纸嫁衣8：千子树》
9. MAIN09《纸嫁衣9：罗浮梦》

每卷使用**官方发布/官方宣传的精美插画、壁纸或角色主视觉**作为入口；旧 App/商店式封面只允许媒体失败时作为备用，不再作为正常主视觉。

权威图片目录：`media/mvu/illustrations/`。

### 左右滑动预览
- 九卷篇章页使用单卡左右滑动轮播，不再展示九宫格/双列封面墙。
- 手机：左右 Swipe；阈值约 56px，纵向滚动优先，不抢酒馆上下滚动。
- 桌面：鼠标/触控笔拖动；同时保留上一卷/下一卷按钮和键盘左右方向键，Tab 可正常遍历控制项。
- 左右滑动**只改变本地预览卷**，绝不写世界书、绝不改 `ACTIVE`、绝不改日期、绝不推进剧情。
- 当前激活卷用小型朱砂印章“当前”标识；预览卷与当前激活卷允许不同。
- 只有点击“进入此卷 / 开始新篇章”才执行真实切卷。
- 主视觉必须读取 manifest 的 `objectPosition`，避免裁掉人物脸、杜言她大型白色蝴蝶结、奚月遥红色发带等识别点。

### 手动切卷铁律
- `沙盒模式` 只表示当前卷结束，可长期自由行动；**绝不自动切卷**。
- 日期到达下一卷默认起点也不得自动切卷。
- 玩家滑到/点到目标篇章后仅进入预览；只有明确点击“进入此卷 / 开始新篇章”才执行切换。
- 确认后进行一次原子操作：关闭其他 MAIN → 开启目标 MAIN → 更新 `ACTIVE` → 必要时 `MAIN_DATE_REBASE` → 进入卷内后启用 `DATE_LOCK`。
- 未确认前不得改 `enabled`、`ACTIVE`、日期或剧情状态。
- `SANDBOX_PENDING` 若保留，只能是 UI 临时状态，不得参与换卷。

## 2. 网易云

只保留一套成熟网易云模块：
- `auto=0`，必须用户手势播放；
- 任意时刻仅一个活动播放器/音源；
- **播放器为 MVU 根节点持久单实例；切换“九卷篇章 / 灯下余音”不得销毁播放器、清空 src 或停止当前歌曲；**
- 合上婚书面板也不得停止当前歌曲；只有用户主动换歌/停止、CHAT_CHANGED 或整个 MVU 真正 dispose 时才替换或释放音源；
- MVU 已挂载后不因新 AI 楼层出现而主动重挂/销毁播放器，避免 iframe 被移动导致断歌；
- 网易云加载失败不得阻断篇章选择；
- 视觉外壳统一成纸嫁衣风格，不显示孤立的第三方后台块。

正式歌单共 **10 首**：九卷对应曲 +《芊芊》。**《海市蜃楼》已移除。**具体映射与已核网易云 ID 见 `media-manifest.v1.json`。

## 3. 远程媒体

复用《狐妖小红娘·梦灯笼》成熟路线：

`GitHub 仓库 → jsDelivr CDN → SillyTavern / MVU 远程加载`

CDN 基址：

`https://cdn.jsdelivr.net/gh/3086013261qq-hue/PaperBride-Lore@main/media/mvu/`

卡体只保存 manifest、远程 URL 和展示逻辑；不得把九张插画以 Base64/图片字节内嵌进角色卡 JSON/PNG。

正常状态读取 `illustrations/`；媒体失败时才允许退回旧封面或“旧纸底 + 卷名”占位，且不得影响选卷按钮业务。

## 4. 视觉方向｜必须是纸嫁衣

关键词：
- 中式民俗悬疑
- 红白喜丧同框
- 旧婚书 / 旧纸纤维 / 暗木 / 纸扎
- 朱砂红 / 暗血红 / 墨黑 / 丧白 / 旧金铜色
- 灯笼背光 / 烟尘 / 剪纸窗格 / 红线 / 符纸折痕
- 克制、阴冷、旧式婚俗感

当前实机“黑底网格 + 米黄大矩形卡 + 巨大说明框”判定为视觉 FAIL，不得作为正式视觉继续保留。

禁止：
- 赛博朋克、RGB霓虹
- 大面积玻璃拟态渐变
- 企业后台/数据仪表盘
- 狐火、苦情树、桃花等《狐妖小红娘》视觉元素
- 《明日方舟》战术终端风
- 可爱粉色婚礼 UI
- 西式哥特十字架/教堂模板
- 满屏 jumpscare 或高频闪烁

### 篇章轮播卡
- 一次只展示一卷主视觉，整卡横向滑动。
- 图片使用宽幅主视觉，标题置于底部轻遮罩，不遮挡人物脸。
- 当前卷标识只用小型朱砂印章“当前”。
- 下方只保留九个小型位置点，不再铺九张缩略卡。
- 预览信息只保留卷名、默认起点、是否当前卷和确认按钮，不使用大块说明框。

### 轻量特效
- 少量纸灰/旧纸微尘（移动端节点建议 ≤12）
- 缓慢红线漂移
- 灯笼式低频呼吸光
- 极轻墨晕/烟雾
- `pointer-events:none`
- `prefers-reduced-motion` 必须降级

## 5. 世界书与 MVU 职责分离

- 人物标志性装饰写在 `characters/` 正式人物正文，不靠 MVU 图片补设定。
- P0 身高/体重/罩杯属于人物正文与视觉推定审计，不属于 MVU。
- 系列梗/彩蛋写在 `worldbook/系列梗与彩蛋_v1.md`，不是 MVU 装饰层。
- MVU 只负责选篇和音乐，表现层不得反向成为世界事实源。

## 6. 移动端

- Android/SillyTavern 优先。
- 触控目标 ≥44px。
- 不依赖 hover。
- 横向 Swipe 只在 `pb-viewport` 内捕获，纵向移动优先交还页面滚动。
- 标题和按钮必须可读，不允许把文字直接压在人物脸上而无轻遮罩。
- 媒体失败、网易云失败、特效失败都不得阻塞选卷。
- 必做实机音乐生命周期测试：`播放 → 切九卷篇章 → 停留 → 回灯下余音`，声音全程不断。
- 必做滑动业务测试：`左右滑动预览多卷 → 不确认` 时 `ACTIVE/enabled/date` 全部不变；点击确认后才原子切换。
