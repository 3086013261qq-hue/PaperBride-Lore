# FOL-03｜F15-F29

<核心设定:阳魂离体>
类型:魂魄状态
定义:肉身仍活着时，活人的“阳魂”因术法、意外或特殊条件离开身体，并以独立视角活动。
已知机制:阳魂可看见部分普通人难以感知的阴物，能触碰特定招阴物和烧给自己的纸扎；肉身与阳魂可被分隔在不同空间。某些夺寿术说法中，阳魂长期不归会被阴差带走。
边界:“七天”等期限来自特定术法/角色陈述，不是所有离魂事件的统一倒计时；王娇彤等案例证明离魂持续时间和后果会因成因、术法与保护条件不同而变化。
</核心设定:阳魂离体>

<核心设定:招阴之物>
类型:阴阳媒介 / 民俗规则
定义:某些材质、植物、旧物或使用过的物品被认为更容易让魂魄接触、附着或感知。
已知机制:游戏内《谈招阴之物》等资料明确举出杨、柳、嫩竹、用过的红包、水等例子；王娇彤阳魂可借部分此类物件间接影响现实。
边界:物品“招阴”不等于必定有鬼，也不意味着所有同材质物品都具有同等效果；以实机可触碰表现优先。
</核心设定:招阴之物>

<核心设定:纸扎烧送>
类型:阴阳物品转换规则
定义:把纸扎物焚烧给特定魂魄后，魂魄侧可能获得与纸扎外形相对应的可用物品。
已知机制:纸剪刀、纸手电、纸手机等都曾在阴侧形成对应功能；game-07 明示“外观看起来像什么，就可能有什么功能”，但功能常不完整，甚至完全不能用。
边界:不是任何纸制品点燃都能生成阴间装备；目标、焚烧意图、纸扎属性和阴阳状态均可能影响结果。
</核心设定:纸扎烧送>

<核心设定:招魂与回魂>
类型:魂魄仪式
定义:通过铃、香、符、熟悉物件、姓名或其他媒介寻找离体魂魄，并尝试引其回到肉身或指定位置。
已知机制:招魂铃、白蜡烛、八音盒、六葬像等在不同作品承担过招魂媒介；魂魄能否回体还受封印、肉身状态、距离与外部术法影响。
边界:招魂不等于复活死人；若肉身已真正死亡或存在更高层阴阳规则，单纯招魂并不能保证还阳。
</核心设定:招魂与回魂>

<核心设定:离魂术>
类型:主动术法
定义:术者主动使自身或他人魂魄脱离肉身的术法总称。
已知机制:杜言她能主动对自己施离魂术进入阴阳界；聂莫黎、道士等也使用过逼魂、离魂或夺寿相关方法。
边界:主动离魂、被迫离魂、濒死魂离体和普通昏迷必须区分；不同术者使用的方法和代价并不统一。
</核心设定:离魂术>

<核心设定:阴阳界与两间口>
类型:异界 / 阴阳交界规则
定义:介于阳世、阴世及更深层阴间之间的异常空间体系，两间口是重要入口和过渡区域。
已知机制:进入后时间感可能突变、现实携带物可能丢失、手机等少数物件仍可保留；不同进入者可看到不同版本的同一空间，同行者也会因空间错位被分开。
边界:阴阳界不是一张固定、所有人共享完全相同的地图；角色对其“由死后想象投影而成”等解释属于理论，不作为唯一客观答案。
</核心设定:阴阳界与两间口>

<核心设定:鬼门与阴司>
类型:死亡秩序 / 阴间制度
定义:鬼门、阴差与阴司共同构成系列中处理亡魂、拘魂、投胎与越界魂魄的规则象征和实际执行体系。
已知机制:阴差会带走符合条件的魂魄；鬼门开闭会影响亡魂通行与投胎；game-08 曾出现“鬼门关闭导致无法投胎”的社会性异常传闻与实机因果。
边界:正式设定只确认作品内实际演出和角色稳定认知，不自行补完整地府官僚结构、轮回层级或现实宗教教义。
</核心设定:鬼门与阴司>

<核心设定:黑白无常>
类型:阴司职能性存在
定义:承担拘魂、押送、执行阴司规则等职能的非普通人类存在。
已知机制:可拘带特定厉鬼或亡魂进入阴司；其行动往往体现“因果/阴司规则正在介入”，而不是私人恩怨。
边界:系列未完整说明其全部权限、个体身份和组织结构；不制作任意战力等级或“召唤黑白无常”通用技能。
</核心设定:黑白无常>

<核心设定:八不郎与鬼货郎身份>
类型:阴间职位 / 身份惩罚 / 规则角色
定义:“八不郎”不仅是原个体名字，也具有可被继承或替换的鬼货郎身份规则。
已知机制:原八不郎长期以封口、交易、引路和囚禁等方式活动，并试图利用金童玉女命格者摆脱自身处境；game-07 结局显示李逢泽、杜言她与“新八不郎”身份发生直接联系。
边界:原八不郎本人和后来的新八不郎不可合并成一个人格；“八不郎”规则的完整起源与职位继承机制仍未完全公开。
</核心设定:八不郎与鬼货郎身份>

<核心设定:无字谶>
类型:预言媒介 / 引导道具
定义:表面无字、在特定条件下显出谶语的异常书册，可持续给持有者提供未来行动提示。
已知机制:谶语会随着持有者接近相关事物而应验或变得可解释；李逢泽、杜言她都曾把无字谶作为进入阴阳界和布局的重要工具。
边界:无字谶并非已证明的绝对预知未来；game-07 已显示谶语可能被布局者利用、设计或形成自我实现效应。
</核心设定:无字谶>

<核心设定:谛听辨妄>
类型:鬼神异兽 / 规则执行
定义:深层阴阳界中具有辨别虚妄、谎言或罪业象征意义的巨大异兽存在。
已知机制:谛听参与game-07终局反算，并与“说谎、被吞食、八不郎身份变化”等结果直接相连。
边界:不把现实佛教谛听典故自动复制进游戏；系列尚未完整说明该个体是否为传统意义上的谛听本尊、其全部判定条件为何。
</核心设定:谛听辨妄>

<核心设定:阴间交易、路引与冥籍>
类型:阴间通行 / 交易规则
定义:阴阳界中的移动和交换常使用冥币、花钱、纸扎物、路引、冥籍等非阳世通行凭证。
已知机制:不同关口、店铺和鬼货郎只接受特定物品或规则交换；路引可作为通行凭证，冥籍与阴间身份/登记相关。
边界:不存在“有冥币就什么都能买”的万能经济系统；具体交易以所在区域和交易者规则为准。
</核心设定:阴间交易、路引与冥籍>

<核心设定:孟婆汤与遗忘>
类型:阴间记忆规则
定义:孟婆汤在game-07阴阳界承担“饮用后与记忆变化有关”的规则象征，并被用于判断角色是否真正失忆。
已知机制:杜言她“没有喝过孟婆汤”成为game-07推理其失忆为伪装的重要证据之一；孟婆咖啡等现代化外观延续了这一遗忘意象。
边界:不把所有阴间饮品都写成必定抹除全部记忆；游戏未给出统一剂量、持续时间或绝对不可恢复规则。
</核心设定:孟婆汤与遗忘>

<核心设定:善秤与业判>
类型:阴间判定规则
定义:game-07 深层阴间用于体现善恶、罪业或“谁站上去”后果的判定装置/规则。
已知机制:剧情推理明确把“恶人站上善秤”与一行人坠入更深地狱的结果连接。
边界:善秤的普遍适用范围、量化善恶方式与是否真正全知均未公开；只保留game-07实机展示的判定功能。
</核心设定:善秤与业判>

<核心设定:金童玉女祭祀>
类型:命格祭祀 / game-07核心仪式
定义:利用符合“金童玉女”条件的一男一女进行的祭祀布局，与杜言她、李逢泽各自追求命格圆满和脱离困局的目的相关。
已知机制:game-07终局推理正式确认“金童玉女祭祀”是杜言她提前布局的核心目的；无字谶、离魂、八不郎交易、回阳名额等均被纳入局中。
边界:作品没有给出可普遍复制的完整仪式说明；不得自行增加“只要八字相合就能成仙/还阳”等固定公式。
</核心设定:金童玉女祭祀>
