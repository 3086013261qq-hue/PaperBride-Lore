# FOL-02｜F10-F14

<核心设定:六王爷与六老太爷>
类型:地方信仰 / 六葬地方化
定义:益昌一带原有“六王爷”地方信仰，郑家后人又借其名义包装六葬体系，将六葬菩萨的信仰内容本地化为“六老太爷”等形式。
已知机制:郑家通过塑像、祭拜、中元庙会和香烛等方式汇聚民间信仰，并把六葬残卷、六王爷名号和家族求福目的绑定。
边界:六王爷不等于六葬菩萨本体；“六老太爷”属于郑家重塑后的地方信仰载体。
</核心设定:六王爷与六老太爷>

<核心设定:太一水脉与水神煞>
类型:地脉 / 地方灾异信仰
定义:益昌郑家认定地下太一水脉“至阴、易聚煞、能成幻障”，并围绕它建立地宫、祭祀与镇压体系。
已知机制:郑家试图通过阴阳相对地宫、五行运转、婚祭和六葬残卷来压制或改造水脉；异常状态下水脉可与幻觉、鬼新娘力量和空间错位叠加。
边界:太一水脉本身不是六葬体系原生神祇；它是郑家把本地水脉观念和六葬术式拼接后的地方化系统。
</核心设定:太一水脉与水神煞>

<核心设定:千子娘与千子树>
类型:旧地方信仰 / 树灵 / 婴灵聚合
定义:千子娘与千子树属于奘铃村更古老的婴童、求子与弃婴因果体系，后被六葬信仰压制或吸纳。
已知机制:千子树长期聚集被遗弃、被献祭或无法正常投胎的婴童魂魄；千子娘相关梦境与祭祀强调“被遗弃者”“求子”“儿童祭品”等主题。
边界:千子娘不是六葬菩萨的另一名字，也不能把所有婴灵都视作其直接分身；树灵、婴灵和村民旧信仰是相互关联但不完全等同的层次。
</核心设定:千子娘与千子树>

<核心设定:樟柳神>
类型:民间邪物 / 术法媒介
定义:game-08 中被瞎师婆实际使用的木制邪物/神灵媒介，能影响人的精神和行为。
已知机制:瞎师婆所持樟柳神木坯来源于千子娘树瘤，并被加工成可施咒、诱导或附着异常影响的媒介；明梅失控时樟柳神直接参与异常演出。
边界:樟柳神的全部民俗来源、独立人格和上限能力未被九部完整说明；不可把它写成全知神祇或千子娘本体。
</核心设定:樟柳神>

<核心设定:阴命与阴命双生>
类型:命理标签 / 祭祀筛选条件
定义:“阴命”是系列中祭祀者、巫术师和村民用来筛选特定对象的命理标签；“阴命双生”则用于描述聂家双胞胎等命理高度相近的特殊情况。
已知机制:阴命常被纸新娘、童子、成仙、契约等仪式当作条件；game-08 中双胞胎命理近同直接影响聂莫琪、聂莫黎的术法联动与半刹鬼仙结果。
边界:命理说法属于游戏世界内玄学体系，不等于现实命理常识；不同术者对“阴命”的计算和解释可能并不一致。
</核心设定:阴命与阴命双生>
