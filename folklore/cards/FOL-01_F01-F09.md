# FOL-01｜F01-F09

<核心设定:六藏与六葬源流>
类型:信仰源流 / 后见历史
定义:奘铃村六葬体系并非天然完整教义，而是在古代经书、地方传说、历代大巫贤解释与后世抄本中不断变形的信仰系统。
已知机制:系列后见信息将“六藏”经书、玄奘相关传说与后来的“六葬菩萨”崇拜连接起来；村民和历代大巫贤逐渐把经书、婚祭、童子、灵塔、修塔使命等拼成一套自洽教义。
边界:不把现实历史中的玄奘直接写成游戏邪教创始人；六葬体系的许多规则是后人断章取义、篡改或地方化后的结果。
</核心设定:六藏与六葬源流>

<核心设定:六葬菩萨与葬尊>
类型:神祇信仰 / 核心象征
定义:奘铃村及其衍生信仰供奉的核心神祇形象，村民多称“葬尊”，大巫贤自称其“口舌”。
已知机制:神像、愿力、祭祀、婚祭、灵塔和经书共同维持六葬信仰；实机多次出现神像掉头、镇压魂灵、愿力汇聚等超自然表现。
边界:这些表现不自动证明“六葬菩萨”是独立、全知、客观存在的真神；正式世界书应区分“信徒教义”“术法载体”“实机现象”。
</核心设定:六葬菩萨与葬尊>

<核心设定:大巫贤制度>
类型:祭司制度 / 权力结构
定义:“大巫贤”是奘铃村跨时代使用的职位与称号，不是单一人物；任职者通常不再以本名作为主要身份。
已知机制:大巫贤主持祭祀、解释葬尊旨意、传承巫术、控制婚祭与修塔制度，并通过宗教权威影响村民；不同时代的大巫贤立场、能力和可靠性并不相同。
边界:民国大巫贤、现代大巫贤、game-06老者不可机械视为同一人；其口述教义不能直接升级为客观宇宙真相。
</核心设定:大巫贤制度>

<核心设定:六葬真经与残卷>
类型:经书 / 教义载体
定义:六葬体系的核心文本及其抄本、残卷，是婚祭、灵塔、巫术和地方改造的重要知识来源。
已知机制:真经、抄本与残卷会被历代持有者重新解释；郑家取得相关残卷后，又把六葬内容与益昌本地六王爷、水脉信仰混合。
边界:残卷内容不保证完整或可靠；“书上写了”不等于世界规则必然如此。
</核心设定:六葬真经与残卷>

<核心设定:纸新娘婚祭>
类型:献祭仪式 / 婚俗异化
定义:六葬体系将符合特定条件的女性包装成“嫁给葬尊”的纸新娘，并通过婚礼形式完成献祭。
已知机制:纸嫁衣、婚书、七月半/中元时节、阴命与童子等元素常被纳入仪式；不同年代和地区出现吊祭、水祭等变体；失败婚祭可能形成跨代执念和厉鬼因果。
边界:不同作品中的纸新娘条件并不完全一致，不应把一作细节强行套到所有地区；“转世后必须继续献祭”属于六葬教义，不等于资料库默认认可的自然法则。
</核心设定:纸新娘婚祭>

<核心设定:阴童子>
类型:祭祀受害者群体 / 魂灵制度
定义:六葬体系中由被献祭儿童形成或被当作“童子”供奉的群体性存在，与纸新娘、灵塔及祭祀守卫功能相连。
已知机制:旧书、神龛和实机均把童男童女、刀剑、发声玩具等供奉规则与儿童献祭联系起来；后世可见童子魂灵或童子像继续参与仪式。
边界:阴童子不是一个固定姓名角色，也不能把所有婴灵、儿童鬼魂都归入阴童子。
</核心设定:阴童子>

<核心设定:煞金刚>
类型:凶煞形态 / 魂魄状态
定义:与梁少平死后魂魄及其被斩首经历强烈相关的无头武生凶煞形态。
已知机制:以武生、斩首、持刀和破坏婚祭为核心意象；其出现长期被大巫贤解释成“被葬尊镇压的凶煞”，后作则逐步揭示其与梁少平的直接关系。
边界:煞金刚不是一个独立于梁少平的新人物，也不能把梁少平生前直接写成会使用煞金刚力量。
</核心设定:煞金刚>

<核心设定:幽刹陀罗>
类型:已命名凶煞 / 未详实体
定义:系列世界观中出现过名称的凶煞或邪物之一。
已知机制:现有九部正式剧情未给出足够稳定的来历、能力、封印条件或人格信息。
边界:仅保留“名称存在、属于异常凶煞语境”的最低层设定；不得自行补造外观、能力、历史、阵营或与六葬菩萨的从属关系。
</核心设定:幽刹陀罗>

<核心设定:魕娘子与鸳鸯债>
类型:厉鬼 / 求嗣契约 / 因果债
定义:魕娘子是纸新娘长期怨念与祭祀因果汇聚出的强大厉鬼形态之一；向其求嗣会形成必须偿还的“鸳鸯债”。
已知机制:求嗣者可获得子嗣，但后代或家族会被卷入偿债条件；魕娘子可与人建立交换、授予部分力量，也会追索未履行的承诺。
边界:魕娘子不是聂莫黎；聂莫黎曾借取/占用其力量，不等于二者同体。不同角色对“债如何偿还”的说法须按作品原文保留，不擅自扩成万能诅咒公式。
</核心设定:魕娘子与鸳鸯债>
