# FOL-05｜F36-F38

<核心设定:罗浮入梦>
类型:长期梦境术法 / 婚祭前置布局
定义:通过持续、可重复、双方都能保留记忆的梦境，把现实中相隔遥远的两个人长期连接起来的术法。
已知机制:赵暮寻、昙露凝在一年以上的梦境中稳定相识、相恋，梦中关系具有连续记忆；术法同时承担“让两人不在现实相见却持续结缘”的培养功能，为后续禳僖游仙正法制造条件。
边界:罗浮入梦不是普通随机梦，也不是“梦中感情都是假的”；两人的选择和情感真实发生，但相识条件被昙父、昙母主动设计。
</核心设定:罗浮入梦>

<核心设定:禳僖游仙正法>
类型:婚祭 / 玄术仪式
定义:game-09《禳僖游仙正法要略》记载的仪式体系，以特定男女的长期异地结缘与最终成婚/解化作为核心条件。
已知机制:经书明示目标女子为“命犯疾煞、多病短寿”，需寻找八字相合男子；二人应南北相隔数千里，长期不得相见，却结缘至少一年，以对应“牛郎织女”“阴阳两隔”之意。昙父、昙母利用罗浮入梦主动培养这些条件，并试图推进最终婚祭。
边界:经书把“成婚后双双解化”写作礼成条件，但九代并未证明该法可以稳定带来长生、成仙或任何单一确定收益；不得把昙父母的目标解释升级成已验证成功机制。
</核心设定:禳僖游仙正法>

<核心设定:断缘>
类型:破局仪式 / 姻缘解除
定义:主动切断被术法、祭祀或强制姻缘利用的“缘线”，以阻止婚祭继续成立的仪式行为。
已知机制:赵暮寻、昙露凝在月老庙相关仪式中选择断缘，从根本上破坏禳僖游仙正法对二人关系的利用；代价表现为罗浮梦结构崩解以及两人失去梦中完整结缘记忆。
边界:断缘不等于否定二人真实感情，也不能泛化成“所有恋爱都能靠月老庙一刀删除”；其效果与game-09特定罗浮术式和婚祭结构直接相关。
</核心设定:断缘>
