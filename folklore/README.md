## 核心边界
1. 角色信仰不自动等于客观宇宙真相。
2. 实机确有超自然演出时照录，但科学/药物解释若同时存在必须保留。
3. 后作补充只进入后见层，不倒灌成前作角色当时已知规则。
4. 原作只给名称、未解释机制的实体只写“已命名/未详”，不补技能树。
5. 民间真实习俗只能作为创作背景，不可反过来证明游戏内规则。
6. 冥陀兰等现实解释与阳魂、阴阳界等灵异演出并存，不做单边裁定。
7. 一切设定最终服务于世界书召回，不为凑数量拆成过细碎片。
