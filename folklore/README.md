# folklore

《纸嫁衣》1～9 民俗 / 术法 / 鬼神 / 仪式设定资料库。

> 状态：**设定工程启动；正式设定总表 v1 建立中。**
>
> 事实基线：`timeline/games/` 九部封版时间线、`timeline/cross-series/` 跨作总线、`characters/` 已封版角色、`locations/` 已封版地点。

## 定位

本目录回答“世界规则是什么”，不承担“谁”“哪里”“何时发生”。

- 人物身份与性格 → `characters/`
- 客观空间 → `locations/`
- 事件先后 → `timeline/`
- 信仰、魂魄、祭祀、术法、鬼神、仪式规则 → `folklore/`

## 正式格式

统一使用：

```text
<核心设定:名称>
类型:...
定义:...
已知机制:...
边界:...
</核心设定:名称>
```

必要时增加 `相关:` / `证据层:`，但不写角色实时行动。

## 核心边界

1. 角色信仰不自动等于客观宇宙真相。
2. 实机确有超自然演出时照录，但科学/药物解释若同时存在必须保留。
3. 后作补充只进入后见层，不倒灌成前作角色当时已知规则。
4. 原作只给名称、未解释机制的实体只写“已命名/未详”，不补技能树。
5. 民间真实习俗只能作为创作背景，不可反过来证明游戏内规则。
6. 一切设定最终服务于世界书召回，不为凑数量拆成过细碎片。
