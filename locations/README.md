## 咩咩全栈地点格式

地点正文统一使用：

```text
<地点:正式名称>
介绍:客观空间描述
</地点:正式名称>
```

只写“照相机式”的物理/空间信息：区域位置、建筑材质、布局、固定设施、空间异常与稳定连接关系；**不写角色当前正在做什么，不写实时剧情状态。**

地点触发只读取 `<status>` 的 `当前位置:`：

```regex
/<status>[\s\S]*?当前位置:[^\n<]*(正式名|简称|必要别名)[\s\S]*?<\/status>/s
```

禁止使用 `<story_scene>` 触发地点。

## 去重原则

1. 同一地点跨作复用只建一张卡，例如奘铃村、益昌镇、郑家大宅。
2. 城镇/区域与内部关键建筑可分层建卡；纯解谜房间、柜子、走廊不单列。
3. 原作有稳定名称时使用原名。
4. 原作没有固定门牌名，但空间规则必须独立触发时，使用 `【制卡标准名】`，不得冒充官方命名。
5. 现实地点与异常映像/幻境若规则、布局和可达关系明显不同，允许拆开。
6. 地点卡不承担剧情因果；剧情事实仍以时间线为准。
