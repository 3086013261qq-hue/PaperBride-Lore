# 007｜给静静的《纸嫁衣》MVU成熟滑卷继承与视觉高保真硬锁 v1.0

> 日期：2026-10-24  
> 状态：**最高优先级 MVU 表现层规范**。  
> 基线：以本单提交后的最新 `main` 为唯一基线。  
> 与 004/005/006 冲突时：业务事实仍服从封版时间线与手动切卷规则；**滑卷底层与视觉表现服从 007。**

## 0. 为什么必须返工

当前实机截图已经证明旧 MVU 表现层 FAIL：

- 顶部是两个普通大矩形 Tab；
- 当前卷信息塞进一大块米黄色说明板；
- 九卷做成两列等宽商品卡墙；
- 图片下面又挂一块大米黄标题底座；
- 黑色网格/后台面板感明显；
- 厚边框、等宽矩形、纵向长列表让它像“素材管理页”，不像《纸嫁衣》；
- 即使换成好看的官方插画，壳体仍然会把画面拉回“开发者原型页”。

**结论：不是继续微调 CSS，而是必须锁死视觉语法。**

### 1.1 《纸嫁衣》必须使用的滑卷实现

- `scroll-snap-type:x mandatory`；
- 每卷 `scroll-snap-align:center`；
- 当前预览卷居中；
- 左右相邻卷必须露出一小部分，提示可滑；
- 手机直接原生 Swipe；
- 桌面/平板可滚动，同时保留左右箭头；
- 键盘左右方向键/Home/End 保留；
- 不再自行用 `pointerdown + translate3d` 模拟滑屏；
- 不再维护拖拽阈值状态机；
- 不再重复造梦灯笼/明日方舟已经解决的交互轮子。

### 1.2 预览与正式切卷仍严格分离

Swipe / 箭头 / 点位 / 点卷面：

- 只更新临时 `previewId`；
- 不改世界书；
- 不改 `ACTIVE`；
- 不改 `enabled`；
- 不改日期；
- 不改 `DATE_LOCK`；
- 不改 `MAIN_DATE_REBASE`；
- 不推进剧情。

只有玩家明确点击：

`进入此卷 / 落印启卷`

才调用现有原子切卷 controller。

# 2. 视觉硬锁：不是“建议”，是构建约束

权威机器可读规范：

`mvu/visual-fidelity.v1.json`

状态：`HARD_LOCK`。

静静不得擅自换成另一套配色/组件结构。

## 2.1 固定色板

- 墨黑：`#100B0C`
- 黑漆：`#1A1012`
- 暗绯：`#321317`
- 血红：`#64191C`
- 朱砂：`#9E332F`
- 旧纸：`#E8DECB`
- 丧白：`#F1E8D9`
- 旧金：`#A88A59`
- 纸灰：`#756A61`

允许明暗透明度变化；不得整体换成米黄后台、霓虹紫蓝、纯黑科技网格或粉色婚礼 UI。

## 2.2 必须同时出现的《纸嫁衣》视觉语法

1. 官方人物/壁纸主视觉必须成为页面最大视觉主体；
2. 暗木/黑漆底，而不是后台网格；
3. 朱砂红只做关键落印、红线与当前卷强调；
4. 旧纸/丧白只做文字与轻量局部纸签，**绝不铺成大面积米黄卡片**；
5. 旧金只做细线、边缘与小标签；
6. 红线姻缘必须有真实 DOM 特效节点；
7. 纸灰/灯影/轻墨雾必须有真实 DOM 节点；
8. 视觉至少有背景层 → 主图层 → 信息层 → 操作层四层；
9. 手机端不得降级成“标题 + 几个矩形按钮”；
10. 去掉标题文字后，仅看构图、色彩、红线、朱砂印与图像占比，仍应一眼是中式民俗悬疑/纸嫁衣，而非普通网页。

# 3. 九卷篇章页：唯一允许结构

## 3.1 顶部

顶部不能再是两个巨大矩形按钮。

固定结构：

- 小型朱砂/旧金“纸”印；
- `PAPER BRIDE · 无间梦境` 小字；
- `纸上姻缘` 主标题；
- 两个窄书签式文字 Tab：`九卷篇章 / 灯下余音`；
- 当前 Tab 只用细朱砂/旧金线标识。

禁止：

- 米黄色大按钮；
- 一整块红底大按钮；
- Bootstrap/Material tab；
- 等宽厚边框管理面板。

## 3.2 主滑卷

唯一允许：

- 一次只突出一个主卷；
- 当前卷占可视宽度约 82～88%；
- 左右邻卷露边；
- 手机竖屏主卷使用偏竖构图（约 `4:5`），让人物插画真正成为视觉中心；
- 宽屏可转 `16:10`；
- 图片直接占卡体绝大部分；
- 文字只叠在底部暗遮罩；
- MAIN 编号做小型角标；
- 当前卷只用小型朱砂印 `当前`；
- 读取 manifest `objectPosition`，不得裁掉脸、蝴蝶结、红发带、星形发夹。

禁止：

- 九宫格；
- 双列封面墙；
- 图片下方大米黄标题底座；
- 商品卡风；
- 每张图厚重相框；
- 一页同时完整展示 4～6 张卷卡。

## 3.3 卷下信息

当前截图中的“大米黄说明框”永久废弃。

固定为一条轻量深色信息带，只允许：

- MAIN ID；
- `CURRENT / 当前` 或 `PREVIEW / 预览`；
- 卷名；
- 默认起点；
- 单个 `进入此卷 / 落印启卷` 按钮。

不得写长篇解释“切换篇章将更换世界书……”；这类技术说明不进入正式 MVU。

# 5. 特效必须真实存在，但轻量

移动端总预算 <=10 个节点。

固定：

- 红线 2；
- 纸灰约 4；
- 灯影 2；
- 墨雾 1。

要求：

- 必须是真实 DOM；
- `pointer-events:none`；
- 低频慢动画；
- `prefers-reduced-motion` 降级；
- 特效失败不能影响点击；
- 禁止 canvas 粒子海；
- 禁止高频闪烁、jumpscare、满屏红光。

# 6. 构建守卫：防止以后又退回丑版

`assembly/build.py` 必须在打包前检查：

### 必须存在
- `mvu/visual-fidelity.v1.json` 且 `status=HARD_LOCK`；
- CSS 含 `scroll-snap-type:x mandatory`；
- CSS 含固定色板关键色；
- UI 存在 `pb-stage / pb-viewport / pb-slide / pb-hero / pb-chapter-meta`；
- UI 使用 `objectPosition`；
- UI 保持音乐单实例。

### 必须不存在
- `pb-grid`；
- `pb-confirm`；
- `pointerdown` 自制拖拽轮播；
- `translate3d` 自制滑卷；
- 双列/三列卷卡墙；
- 大米黄说明板旧结构。

任意一项不满足：**build 直接失败，不得产候选 JSON/PNG。**
