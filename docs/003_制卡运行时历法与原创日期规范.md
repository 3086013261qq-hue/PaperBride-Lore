# 003｜制卡运行时历法与原创日期规范

> 适用范围：后续咩咩制卡包·全栈世界书、角色卡、MVU、事件调度与日期状态。
>
> 核心原则：**原作事实层与制卡运行时历法层永久分离。** 原作没有给出公历年份时，允许为了可运行性补充原创年月日，但必须明确标记为 `【制卡原创锚定】`，不得反写成官方设定。

---

## 1. 两层时间体系

### 1.1 原作事实层
来源：`timeline/games/`、`timeline/cross-series/总时间线.md`。

规则：
- 原作明确年月日/时刻：原样保留。
- 原作只给时代、农历、节日、相对先后：只写到原作能支持的精度。
- 原作未给年份：不得在事实层补造。
- 后作新增真相只进入跨作后见层，不回写污染前作角色当时认知。

### 1.2 制卡运行时历法层
来源：`timeline/cross-series/制卡运行时总年表.md`。

规则：
- 咩咩全栈中的所有主线事件必须拥有可解析的 `YYYY-MM-DD`；必要时细到 `HH:MM`。
- 官方已有时间锚点优先；缺失部分使用原创日期补齐。
- 原创补齐统一标记：`【制卡原创锚定】`。
- 制卡日期只服务于运行时、MVU显示和玩家自由行动，不改变原作事实层。

---

## 2. 现代主线固定运行时顺序

正式采用：

`game-01 → game-02 → game-03 → game-04 → game-05 → game-06 → game-07 → game-08 → game-09`

说明：
- 该顺序**不是因为作品编号必须顺排**，而是重新结合原作相对时间锚点后得到的制卡运行时顺序。
- game-07 明示王娇彤自《鸳鸯债》后已阳魂离体“约一年”，因此将 game-07 锚定到 2023-02-04，距离 game-03 起点约一年零二十天。
- game-08 明示发生在 game-01 约三年后，因此继续锁定 2023-09-03，与 game-01 起点相隔整三年。
- game-09 必须晚于 game-07，因为九代片尾已经使用七代结局后的李逢泽、杜言她状态；同时锚定到 2024-11-15，对应农历十月十五/下元节。
- 除原作已明示部分外，该排序仍属于**制卡运行时原创年表**，不宣称为官方公布年表。

## 4. 自由行动窗口

每次主线完成后进入长期自由期；**卷与卷之间不自动切换**。

| 前一主线结束 | 下一主线默认开始 | 默认自由期 |
|---|---|---:|
| game-01 2020-09-04 | game-02 2021-08-22 | 352天 |
| game-02 2021-08-23 | game-03 2022-01-15 | 144天 |
| game-03 2022-01-16 | game-04 2022-04-30 | 103天 |
| game-04 2022-05-01 | game-05 2022-08-06 | 96天 |
| game-05 2022-08-07 | game-06 2022-11-19 | 103天 |
| game-06 2022-11-20 | game-07 2023-02-04 | 75天 |
| game-07 2023-02-05 | game-08 2023-09-03 | 209天 |
| game-08 2023-09-04 | game-09 2024-11-15 | 437天 |

自由期允许：
- 日常互动、恋爱、旅行、工作、调查、疗养。
- 玩家原创支线与非冲突事件。
- 为后续主线做准备，但不得提前揭露尚未知晓的后见真相。
- 世界时间自然推进。

自由期不得：
- 自动宣告下一卷已经发生。
- 因“日期到了”自动切换 MAIN。
- 因当前日期超过默认锚点而跳过尚未手动开启的篇章。

## 5. 主线进入与日期校准

### 5.1 日期不是自动剧情播放器

主线必须满足：
1. 对应篇章未完成；
2. 当前卷已结束并处于稳定自由期；
3. **玩家在 MVU 明确选择进入目标卷**；
4. 世界书/运行时允许启用该篇章。

仅“日期到了”绝不触发换卷。

### 5.2 玩家在自由期玩得过久

若玩家自由行动使当前日期超过下一卷默认锚点：
- 不回滚玩家已经历时间；
- 不跳过该卷；
- 玩家手动开启下一卷时执行一次 `MAIN_DATE_REBASE`，将该卷整体顺延到当前日期或其后的合理日期；
- 卷内相对时刻、跨午夜顺序和事件间隔保持不变。

### 5.3 已进入主线后

一旦正式进入某卷：
- 本卷内部时间进入 `DATE_LOCK`。
- 关键时刻按该卷运行时日期推进。
- 未完成本卷前不得进入另一卷。
- 主线完成后解除 `DATE_LOCK`，进入稳定 `沙盒模式`。
- `沙盒模式` 只表示本卷完成与自由行动，**不承担自动 MAIN_HANDOFF**。

---

## 6. 事件节点日期生产规则

1. 每个 A/A1/A2 节点必须拥有具体 `YYYY-MM-DD`。
2. 原作给出时刻的节点同时写 `HH:MM`。
3. 同一夜跨零点必须真实换日。
4. 无原作时刻的同章节点可按叙事顺序分配合理时段，并标记 `【制卡原创时刻】`。
5. 纯谜题步骤不因日期要求重新进入正式时间线。
6. 历史旧事的现代日期表示“角色在该日经历/获知该旧事”，不把历史事实改写成现代发生。

- `【官方明示日期】`
- `【官方明示时刻】`
- `【制卡原创锚定】`
- `【制卡原创时刻】`
- `【原作农历校准】`
- `【MAIN_DATE_REBASE】`
- `【DATE_LOCK】`

---

## 8. 禁止项

- 禁止把原创锚定写成官方事实。
- 禁止仅因作品编号顺序决定宇宙因果；本次恰好排成 1→9，是相对时间约束重新校准后的结果。
- 禁止 game-09 早于 game-07。
- 禁止用日期驱动覆盖剧情状态。
- 禁止稳定 `沙盒模式` 自动切卷。
- 禁止 `沙盒模式过渡`、`至 沙盒模式过渡`、`过渡到沙盒模式`、`即将进入沙盒` 触发换卷。
