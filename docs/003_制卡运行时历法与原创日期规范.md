# 003｜制卡运行时历法与原创日期规范

> 适用范围：后续咩咩制卡包·全栈世界书、角色卡、MVU、事件调度与日期状态。
> 
> 核心原则：**原作事实层与制卡运行时历法层永久分离。** 原作没有给出公历年份时，允许为了可运行性补充原创年月日，但必须明确标记为 `【制卡原创锚定】`，不得反写成官方设定。

---

## 1. 两层时间体系

### 1.1 原作事实层

来源：`timeline/games/`、`timeline/cross-series/总时间线.md`。

规则：
- 原作明确年月日/时刻：原样保留。
- 原作只给时代、农历、节日、相对先后：只写到原作能支持的精度。
- 原作未给年份：不得在事实层补造。
- 后作新增真相只进入跨作后见层，不回写污染前作角色当时认知。

### 1.2 制卡运行时历法层

来源：`timeline/cross-series/制卡运行时总年表.md`。

规则：
- 为咩咩全栈需要，所有主线事件最终必须拥有可解析的 `YYYY-MM-DD`；需要时可进一步细到 `HH:MM`。
- 官方已有时间锚点优先；缺失部分使用原创日期补齐。
- 原创补齐统一标记：`【制卡原创锚定】`。
- 制卡日期只服务于运行时推进、MVU显示、世界书切换与玩家自由行动，不改变原作事实层。

---

## 2. 现代主线固定运行时顺序

正式采用：

`game-01 → game-02 → game-03 → game-04 → game-05 → game-06 → game-08 → game-07 → game-09`

说明：
- game-01～06 保留现有跨作因果顺序。
- game-08 明示发生在 game-01 约三年后，因此固定到 2023-09-03，并插入 game-06 与 game-07 之间。【制卡原创锚定】
- game-09 必须晚于 game-07，因为九代片尾已经使用七代结局后的李逢泽、杜言她状态；因此 game-09 不得插到 game-07 之前。
- 该排序是**制卡宇宙运行时顺序**；除原作已明示部分外，不宣称官方作品真实年表就是此顺序。

## 4. 自由行动窗口

主线之间禁止无缝硬切。每次主线完成后，默认进入可供玩家操作的自由期：

| 前一主线结束 | 下一主线开始 | 可用自由期 |
|---|---|---:|
| game-01 2020-09-04 | game-02 2021-08-22 | 约 352 天 |
| game-02 2021-08-23 | game-03 2022-01-15 | 约 145 天 |
| game-03 2022-01-16 | game-04 2022-04-30 | 约 104 天 |
| game-04 2022-05-01 | game-05 2022-08-06 | 约 97 天 |
| game-05 2022-08-07 | game-06 2022-11-19 | 约 104 天 |
| game-06 2022-11-20 | game-08 2023-09-03 | 约 287 天 |
| game-08 2023-09-04 | game-07 2023-10-28 | 约 54 天 |
| game-07 2023-10-29 | game-09 2023-11-27 | 约 29 天 |

自由期允许：
- 日常互动、恋爱、旅行、工作、调查、疗养。
- 玩家原创支线与非冲突事件。
- 为后续主线做准备但不得提前揭露角色尚未知晓的后见真相。
- 世界时间自然推进。

自由期不得：
- 自动宣告下一主线已经发生。
- 因“当前日期超过锚点”而跳过玩家尚未触发的正式篇章。
- 用后作结局提前改变当前人物状态。

## 5. 主线触发与日期校准规则

### 5.1 日期不是自动剧情播放器

主线必须同时满足：
1. 对应篇章未完成；
2. 剧情触发条件成立；
3. 世界书/运行时允许进入该篇章。

仅仅“日期到了”不得自动把剧情标记为完成。

### 5.2 玩家在自由期玩得过久

若玩家自由行动使当前日期超过下一篇章原定锚点，而下一篇章尚未触发：
- 不回滚玩家已经经历的时间；
- 不偷偷跳过主线；
- 下一篇章真正触发时，允许执行一次 `MAIN_DATE_REBASE`，把篇章锚定日整体顺延到当前日期或其后的合理日期；
- 篇章内部相对时刻、跨午夜顺序与事件间隔保持不变。

即：**锚点用于默认开局和官方主线排序，不用于惩罚玩家自由游玩。**

### 5.3 已进入主线后

一旦正式进入某一篇章：
- 本篇章内部时间进入 `DATE_LOCK`。
- 关键时刻按该篇章运行时日期推进。
- 未完成本篇章前，不得自动切到下一部。
- 主线结束后解除 `DATE_LOCK`，重新进入自由行动状态。

## 6. 事件节点日期生产规则

后续把 939 个逐作节点转成咩咩 `<world_timeline>` 时：

1. 每个 A/A1/A2 节点必须拥有具体 `YYYY-MM-DD`。
2. 原作给出时刻的节点同时写 `HH:MM`。
3. 同一夜跨零点必须真实换日，不允许所有事件硬塞在同一天。
4. 没有原作时刻的同章节点可按叙事顺序分配合理时段，但标记 `【制卡原创时刻】`。
5. 纯谜题步骤仍不进入正式时间线；只给剧情节点分配日期。
6. 历史旧事另行建立历史运行时锚定年，不与现代主线混用。

---

## 7. 标签规范

- `【官方明示日期】`：游戏/官方直接给出。
- `【官方明示时刻】`：游戏画面直接给出。
- `【制卡原创锚定】`：为运行时补的年月日。
- `【制卡原创时刻】`：为同日节点排序补的时刻。
- `【原作农历校准】`：原创公历日期用于匹配原作明确农历/节日。
- `【MAIN_DATE_REBASE】`：玩家自由行动导致主线启动日整体后移。

---

## 8. 禁止项

- 禁止把 `【制卡原创锚定】` 写进“官方设定/原作事实”字段。
- 禁止为了满足作品编号强行写成 1→2→3→4→5→6→7→8→9。
- 禁止 game-09 早于 game-07，因为九代彩蛋已经使用七代结局后的角色状态。
- 禁止用日期驱动直接覆盖剧情状态。
- 禁止玩家多玩几天后系统自行宣告未触发主线已经结束。
