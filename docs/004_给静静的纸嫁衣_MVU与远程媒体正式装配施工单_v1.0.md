## 一、唯一业务范围

本卡 MVU **只能有两个用户功能模块**：

1. **九卷手动篇章选择**
2. **网易云音乐播放器**

禁止静静自行增加：
- 人物状态页
- 背包/物品栏
- 收藏册/图鉴
- 地图页
- 成就
- 剧情进度条
- 事件导演
- 自动换卷
- 自动 MAIN_HANDOFF
- Opening/MP4 视频页
- 第二套剧情状态系统
- 第二套世界事实源
- 与用户要求无关的“为了丰富功能”扩展

如果美术表现与业务稳定性冲突，**业务稳定性优先**。

## 三、切卷业务｜只能玩家手动触发

### 3.1 禁止自动换卷

以下任何条件都**不得**自动进入下一卷：
- 日期到达下一 MAIN 默认起点
- 当前 MAIN 进入 `沙盒模式`
- `沙盒模式过渡`
- `至 沙盒模式过渡`
- `过渡到沙盒模式`
- `即将进入沙盒`
- `SANDBOX_PENDING`

纸嫁衣卷间时间跨度长，稳定沙盒的意义只是：
**“本卷正式剧情结束，玩家进入长期自由行动期。”**

### 3.2 手动选择流程

九张官方封面作为篇章入口。

点击封面：
1. 只打开该卷预览/确认层；
2. 显示卷名、默认运行时起点、当前是否 ACTIVE；
3. 不立即修改任何世界书状态；
4. 用户再次点击 **“进入此卷 / 开始新篇章”** 后才执行原子切换。

### 3.3 原子切换事务

用户确认后一次完成：
1. 关闭 MAIN01～MAIN09 中除目标卷外的剧情卷 `enabled`；
2. 开启目标 MAIN；
3. 设置 `ACTIVE=MAINxx`；
4. 若为首次按默认时间启动，使用该卷默认锚点；
5. 若玩家自由行动已经越过默认起点，使用 `MAIN_DATE_REBASE` 整卷顺延，不回滚世界时间；
6. 正式进入目标卷后启用 `DATE_LOCK`，只约束卷内相对时序。

事务失败必须回滚，不允许出现“两个 MAIN 同时 enabled”或“ACTIVE 与 enabled 不一致”。

### 3.4 二次确认

如果当前已有另一个 ACTIVE MAIN 或正在其沙盒期，切到不同卷前必须出现简短二次确认：
“切换篇章将更换当前主线世界书，既有历史不会被删除。”

禁止加入解锁货币、等级、自动顺序锁等用户未要求机制。

## 五、网易云模块｜只复用成熟模块，不重造

## 六、MVU 视觉｜纸嫁衣风格限制死

### 6.1 核心气质

必须是：
**中式民俗悬疑 + 红白喜丧 + 旧纸木纹 + 灯影 + 纸扎 + 克制阴冷。**

主色：
- 墨黑 / 炭黑：`#15110F` / `#211916`
- 旧纸米白：`#E7D8B8` / `#CDBB96`
- 朱砂红：`#9F2725`
- 暗血红：`#5E1718`
- 旧金/铜：`#A9854D`
- 丧白：`#EEE8DC`
- 极少量阴冷青灰只作鬼气点缀：`#839A96`

视觉素材语言：
- 毛边旧纸
- 宣纸纤维
- 暗木纹
- 红线
- 剪纸窗格
- 符纸折痕
- 灯笼背光
- 纸灰/烟尘
- 非对称留白
- 红与白喜丧意象并置

### 6.2 绝对禁止

- 赛博朋克
- RGB 霓虹
- 蓝紫科技光
- 大面积玻璃拟态 / glassmorphism
- 企业后台 dashboard
- 一堆僵硬黑色矩形卡片
- 《明日方舟》战术终端风
- 《狐妖小红娘》的狐火、苦情树、桃花、缘签视觉
- 可爱粉色婚礼风
- 西式哥特教堂/十字架模板
- 满屏高频闪烁
- jumpscare 弹脸
- 为“恐怖”牺牲文字可读性
- 使用难以阅读的伪书法字体做正文

### 6.3 篇章页

- 九张封面是绝对视觉主体；
- 桌面端可 3 列，手机端默认 2 列；
- 卡片边缘做旧纸/暗木/细旧金线，不做后台面板；
- 封面上只叠简短卷号与标题；
- 文字区必须有暗纸/渐变遮罩，不能压脸；
- 当前 ACTIVE 卷用低饱和朱砂红 + 旧金描边，不能用荧光边框；
- 选中卷展开的确认区全宽显示。

### 6.4 音乐页

- 外壳像旧式唱片签/戏单/纸扎唱片页；
- 仍是一个网易云模块，不做九个独立播放器；
- 当前歌曲标题、歌手、所属篇章清晰；
- 九首主题曲可显示对应卷号；两首 EXTRA 单独归入“余音”。

### 6.5 轻量特效

允许：
- 纸灰/旧纸微尘，移动端节点建议 `<=12`；
- 1～2 根非常慢的红线漂移；
- 灯笼式低频呼吸光；
- 极轻墨晕/烟雾淡入；
- 页面切换轻微淡入/上浮。

要求：
- 特效必须有真实 DOM 才算实现；
- `pointer-events:none`；
- `prefers-reduced-motion` 降级；
- 不依赖 canvas；
- 特效失败不能影响按钮。

## 七、移动端硬验收

Android / SillyTavern 优先：
- 所有触控目标 >=44px；
- 不依赖 hover；
- 两列封面在常见手机宽度不溢出；
- 选中卷展开确认按钮可点击；
- 滚动不卡死；
- 网易云切歌后旧音源停止；
- CDN 图片断网时仍能选卷；
- `prefers-reduced-motion` 下仍正常可用；
- 页面销毁后无悬空 iframe/audio。
