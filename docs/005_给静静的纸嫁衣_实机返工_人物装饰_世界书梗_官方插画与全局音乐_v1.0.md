## 三、当前 MVU 美术推倒重做，但业务不动

当前实机“黑底网格 + 米黄矩形卡 + 大块说明框”的呈现判定为：**视觉 FAIL、业务可保留**。

禁止改：
- 两页业务：九卷篇章 / 灯下余音；
- 手动换卷；
- enabled / ACTIVE 原子切换；
- DATE_LOCK / MAIN_DATE_REBASE；
- 禁止自动换卷。

必须重做表现层：

### 1. 总体气质
关键词：
`旧婚书 / 纸页 / 朱砂 / 暗木 / 丧白 / 旧金 / 灯影 / 墨晕 / 红线 / 中式民俗悬疑`

不允许：
- 黑色后台网格；
- 企业管理面板；
- 纯米黄矩形堆叠；
- 赛博霓虹；
- 玻璃拟态；
- 明日方舟终端风；
- 狐妖狐火/桃花视觉。

### 2. 篇章页结构
手机端推荐：
- 顶部：极窄双页签，做成朱砂印签/旧纸书签，不再使用两个巨大的矩形按钮；
- 当前卷：一张全宽 16:9 左右的“主视觉页”，直接展示当前卷官方插图；标题、默认时间、当前状态以小字号叠在下方渐变/旧纸条，不遮脸；
- 进入本卷按钮：像朱砂盖印/婚书落款，不做后台按钮；
- 下方九卷：双列图片卡可以保留，但**图片占卡面至少 80%**，标题直接压在底部轻渐变或窄纸签上，不再有大块米黄文字底座；
- 当前卷标识：改为小型朱砂角签/印章“当前”，禁止现在那条硕大的“当前篇章”竖牌。

九张图片必须优先保证人物脸部、标志性头饰和双人构图完整，`object-fit:cover` 不能随意把人物识别点裁掉。

### 3. 轻量视觉细节
可以使用：
- 纸张纤维/旧印刷纹理；
- 很淡的墨晕；
- 1～2 根红线；
- 极少纸灰；
- 灯笼暖光；
- 朱砂印章式选中反馈。

特效 `pointer-events:none`，低频，Android 降级；不得为了氛围牺牲点击。

### 播放器生命周期硬规则
- 音源/iframe 实例挂在 MVU 根节点的**持久层**，不得挂在 `renderMusicPage()` 会被替换的页面容器里。
- 点击“九卷篇章 / 灯下余音”只切换可见控制 UI，不 remove iframe、不清 `src`、不重建播放器。
- 用户主动换歌时才替换当前音源；主动停止时才停止。
- 离开音乐页继续播放；回到音乐页显示同一首歌、同一播放器实例。
- 任意时刻最多 1 个活动音源。
- MVU 整体真正 dispose / 聊天销毁时才释放音源。
- `auto=0` 保持，第一次播放必须来自用户手势。

必须做 Android/SillyTavern 实机：
`音乐页播放 → 切篇章页 → 停留 → 回音乐页`，全过程声音不得中断。
