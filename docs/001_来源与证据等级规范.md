# 001｜来源与证据等级规范

本文件定义 PaperBride-Lore 所有剧情、角色、地点与跨作资料的证据使用规则。

## 一、来源优先级

由高到低：

1. 游戏实际演出、对白、道具文本、可读文书、结局与彩蛋
2. 官方网站、官方账号、官方设定/宣传资料
3. BWIKI 等逐章攻略、角色页与资料页
4. 高质量完整图文攻略、无跳剧情实况
5. 玩家剧情解析、社区讨论

低等级来源只能用于补流程、查漏或提供检索线索，不得推翻高等级来源。

## 二、正式证据标签

- `【明示】`：游戏或官方资料直接确认。
- `【流程还原】`：连续攻略/实况足以确认事件发生，但尚未取得更高等级逐字证据。
- `【待核】`：可能成立，但仍需更高等级来源复核。
- `【推测】`：研究笔记专用，禁止作为正式剧情事实进入封版时间线。

## 三、解释层分离

当作品同时提供灵异、宗教、医学、梦境、幻觉等不同解释时：

- 分别记录“角色实际经历”“角色/文本提出的解释”“后续作品追加的信息”。
- 不替原作裁定唯一真相。
- 后作揭示不得倒灌成前作角色当时已经知道的事实。

## 四、来源登记要求

每一作必须在 `sources/game-XX/source-registry.md` 中登记：

- 来源名称与 URL
- 覆盖章节/范围
- 可支撑的信息类型
- 局限与风险
- 当前校准状态

## 五、网络内容污染规则

以下内容不得直接进入正式资料：

- 攻略作者的吐槽、评价与自行总结的动机
- 玩家二创设定
- 无原作证据的前世、转世、幕后身份、死亡原因
- 为补逻辑而自行编造的日期、对白或仪式规则

正式资料始终以“原作能证明到什么程度”为上限。
