# 000｜《纸嫁衣》资料库项目总规则

## 一、阶段顺序

本工程严格按以下顺序推进：

1. 逐作剧情资料整理
2. 逐作细颗粒时间线
3. 跨作总时间线与前后呼应核对
4. 角色资料
5. 地点资料
6. 民俗 / 术法 / 鬼神 / 仪式资料
7. 世界书与角色卡结构设计
8. MVU / 媒体 / 最终装配

当前阶段只做 1～2。

## 二、来源优先级

由高到低：

1. 游戏实际流程、剧情演出、对白、道具文本、可读文书
2. 官方发布资料、官方账号、设定集
3. BWIKI 逐章攻略与角色页
4. 高质量完整图文攻略 / 无跳剧情流程
5. 玩家剧情解析

低优先级来源不得推翻高优先级来源。

## 三、证据标签

- `【明示】`：游戏演出、对白、文本或官方资料直接确认。
- `【流程还原】`：攻略连续步骤足以确认事件确实发生，但尚未拿到原始对白/演出逐字校准。
- `【待核】`：信息可能成立，但仍需视频、原文或更高等级来源核对。
- `【推测】`：仅用于研究笔记，禁止直接进入正式剧情事实。

正式时间线原则上只保留前三类；`【推测】`必须隔离。

## 四、时间规则

1. 游戏明确给出日期时照录。
2. 仅给出农历、节日、相对天数时照录相对时间，不擅自换算公历年份。
3. 无明确年份时写“年份未明”，禁止补造具体年份。
4. 跨作品先后关系只有在原作明确或证据链充分时才写死。

## 五、剧情还原规则

- 解谜步骤只在其承载剧情信息时进入时间线。
- 密码、小游戏本身一般不进入正式剧情，除非线索揭示人物关系、历史、仪式或地点信息。
- “谁做了什么”“谁看见什么”“谁告诉谁什么”“哪个仪式被启动/打断”“地点如何变化”是时间线核心。
- 攻略作者的评价、吐槽、猜测全部剔除。

## 六、格式

逐作正式时间线采用：

```text
A
A1
A2
A3
B
B1
B2
```

A/B 为事件组；A1/A2 等为细事件。节点应尽量做到一节点一事实。

## 七、禁止事项

- 禁止把玩家解析写成原作明示。
- 禁止为增强戏剧性补对白。
- 禁止把后作揭示的真相倒灌成前作角色当时已经知道的信息。
- 禁止因角色页总结而跳过实际剧情流程。
- 禁止把谜题通关顺序误当作世界观因果。
