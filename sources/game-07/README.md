## 三、关键证据锚点

### 1. 阴阳界与时间/空间异常

- 柳逢泽进入两间口镇异域后，建筑仍似原地但细节改变，判断自己已经不在阳世。
- 手机从中午直接显示为傍晚，背包中的法器、符咒无法带入，手机无信号。
- 阴阳界空间会因人而异；同路同行者也可能在下一处入口分散。

### 2. 杜言她失忆与阳魂离体

- 第一章末柳逢泽终于找到杜言她，但杜言她明确表示“不认识你”。
- 第三章王娇彤确认杜言她属于“活人肉身尚存、阳魂离体”的状态；杜言她后来承认自己一直以为已经死亡，并持续饮用孟婆咖啡逐日遗忘。

### 3. 申墨卿 / 王娇彤跨作状态

- 申墨卿为寻找失联一年的王娇彤阳魂进入两间口阴阳界。
- 王娇彤肉身仍在阳间，身体机能恶化；其阳魂可使用烧给她的纸扎物品。
- 第三章二人重逢；王娇彤仍处于阳魂状态。

### 4. 无字谶与“朝闻道”

- 柳逢泽持有《无字谶》，并以其谶语推进探索。
- 申墨卿透露自己从张辰瑞创建的灵异交流网站得到网名“朝闻道”的高人指点，才进入阴阳界深处。
- 后段揭示“朝闻道”实际就是李逢泽本人；此前属于其隐藏身份，正式时间线不得前置为申墨卿已知。

### 5. 第五章推理树

游戏内推理明确给出：

- “无字谶 → 杜言她”
- “照片 → 仪式用品”
- “同道中人 → 杜言她”
- “进入阴阳界 → 我有无字谶”
- “八不郎的交易 → 杜言她”
- “阴谋 → 引我交易”
- “抓入牢房 → 言她拿了货物”
- “彤彤被抓 → 被言她拉住了”
- “孟婆汤 → 没喝过”
- “堕入地狱 → 善秤上了恶人”
- “离魂 → 离魂之术”
- “原因 → 提前布局”
- 最终“她的目的 → 金童玉女祭祀”。

这是正式时间线中“杜言她提前布局”的最高等级直接证据。

### 6. 李逢泽的真实身份与动机

- 前期使用“柳逢泽”姓名；真实姓名为李逢泽。
- 曾受柳大师控制；因厌胜邪术威胁而避免使用真名。
- 为补全自身“金童”命格，主动寻找符合“玉女”条件的对象，与杜言她交往本身即带有祭祀目的。
- 其救回杜言她并非纯粹无私，也包含让祭祀继续完成的私心。

### 7. 杜言她的真实布局

- 杜言她并非完全被动卷入；她提前进行离魂与阴阳界布局，并设法把王娇彤卷入，目的同样与“金童玉女祭祀”有关。
- 第五章柳逢泽通过推理当面对质后，她放弃继续伪装。

### 8. 最终结局

- 李逢泽以红绳把自己与杜言她连接，试图共享回阳名额。
- 杜言她借谛听验证李逢泽的真实目的；二人确认彼此都曾准备利用对方。
- 二人之后选择暂时合作，准备寻找其他满足条件的“金童/玉女”。
- 跳下回魂崖后并未真正安全返回阳间，而是落入八不郎的换命骗局。
- 谛听吞噬二人，原八不郎借机脱身；李逢泽与杜言她成为新的鬼货郎/八不郎。
- 申墨卿与王娇彤则成功团聚并返回阳界。

## 四、正式时间线禁止事项

- 不把“柳逢泽”在第一章就直接写成所有人都知道的“李逢泽”。
- 不把杜言她写成唯一幕后黑手；李逢泽同样有祭祀私心。
- 不把李逢泽写成纯情无私救妻者，也不把杜言她写成单纯受害者。
- 不把申墨卿与王娇彤在第三章重逢直接等同为“已还阳”；两人直到结尾才完成返回。
- 不把孟婆咖啡造成的失忆当成普通酒精/药物效果；按游戏阴阳界设定记录。
- 不提前使用《纸嫁衣9》后续彩蛋改写第七部结局。
