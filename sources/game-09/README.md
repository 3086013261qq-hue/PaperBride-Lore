- 赵暮寻与昙露凝并非现实先认识，而是在父母术法安排下于梦中相识。
- 两人相识持续一年以上，并形成真实感情，但这个“相遇条件”本身是人为设计。

### 禳僖游仙正法
游戏文本可确认的施展条件包括：
1. 女方命犯疾煞、体弱短寿；
2. 需寻找八字相合男子；
3. 二人南北相隔数千里；
4. 岁岁不得相见，却需结缘一年以上；
5. 以“牛郎织女、阴阳两隔”之意完成婚祭。
