## 本作必须隔离的解释层

### 1. “精神病院才是真现实”
第四折出现“钟医生 / 第十三医院 / 荀元丰只是保安”的完整现实解释，但它发生在屠浮生针对陶梦嫣施加的幻境中。正式时间线只能标为【幻术内叙事】，禁止覆盖主线现实。

### 2. 冥陀兰与术法
屠浮生明确利用戏院空调中的冥陀兰致幻花粉，同时又使用家传鬼戏、地支鬼儡法、灵府魇魅术等。正式资料同时记录两者，不擅自宣布“全部只是药物”或“药物完全无关”。

### 3. 荀元丰与梁少平
本作明确以“梁少平转世”处理荀元丰，但陶梦嫣也强调“你不是他，你是荀元丰”。正式线必须同时保留前世关系与今生人格独立，禁止把两人写成同一人格。

### 4. 结局状态
本作结束时，荀元丰是【肉身仍在、魂魄离体】；陶梦嫣前往益昌镇寻找阴阳裂隙；钟梓萓留下照看肉身、等待医生和警察。后续作品中的还阳结果不得倒灌为本作结尾已发生。
