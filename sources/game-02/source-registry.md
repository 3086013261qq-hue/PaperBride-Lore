## 证据处理规则

1. 角色亲口陈述的“信仰说法”不自动等同客观真相，例如大巫贤关于“千年煞金刚”“葬尊降怒”的话，只能记为【角色陈述】。
2. 陶梦嫣亲身经历的梦境/前世片段，记为【明示·主观经历】；是否真为转世，不由资料库自行裁定。
3. 结尾肖医生提出“冥陀兰致幻 + 童年催眠灌输”的解释，记为【明示·医学解释】，不得据此否定全部灵异经历。
4. 反过来，也不得用后续作品的灵异真相去否定肖医生在本作中真实提出过这一解释。
5. “祝小红=陶梦嫣前世”“梁少平残魂=煞金刚”只有在逐章对白/演出支撑到对应程度时才写入，不提前倒灌角色认知。

## 本作关键锚点

- 陶梦嫣长期反复梦见自己穿纸嫁衣、被绑在老树旁，因此返回故乡奘铃村查明原因。
- 村中大巫贤与村民把她认作“纸新娘”，企图进行婚祭。
- 她在葬宫和鬼戏楼逐步接触梁少平、祝小红旧事，并在第四章以梁少平视角重演百年前婚祭悲剧。
- 第五章中陶梦嫣释放/安抚煞金刚相关魂魄，进入六葬灵塔，烧毁重要经书并逃离。
- 事件后村长等人因绑架未遂等罪名等待审判。
- 肖医生提出冥陀兰致幻与童年催眠解释，并对奘铃村仪式产生研究兴趣。
